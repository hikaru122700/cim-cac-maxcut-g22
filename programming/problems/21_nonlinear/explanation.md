# 問題4-2: 非線形効果(自己位相変調 SPM)による位相変化

## 問題

標準単一モード光ファイバ($\gamma = 2.1\ \mathrm{W^{-1}km^{-1}}$)において、**非線形効果のみ**を考えて伝搬させる。
強度ピーク 1 W、強度 FWHM 10 ps のガウスパルスを入力し、**ピーク位置における位相変化量の $z$ 依存性**を求める。
さらに **解析解を導出**して比較する。

## 実行結果(出力)

```

非線形長 L_NL = 1/(γ P0) = 0.4762 km

  z [km]  φ_peak(sim) [rad]   φ_peak(theory) [rad]
     0.0              0.000                  0.000
     1.0              2.100                  2.100
     2.0              4.200                  4.200
     5.0             10.500                 10.500

数値 vs 解析解 最大絶対誤差 = 8.88e-16 rad
```

## 1. 非線形効果(光カー効果)と SPM

光強度が強いと、ファイバの屈折率がわずかに強度に応じて変化する(**光カー効果**)。
すると光は自分自身の強度で位相変調を受ける。これを **自己位相変調(SPM, Self-Phase Modulation)** という。
包絡線方程式は、分散・損失を無視すると

$$ \frac{\partial A}{\partial z} = j\,\gamma\,|A|^2\,A. $$

## 2. 解析解の導出

この方程式は簡単に解ける。両辺を $A$ で見ると、$|A|^2=A A^*$ は $z$ について不変であることがまず分かる
(位相だけ変わり振幅は変わらない)。実際、$\partial|A|^2/\partial z = A^*\partial_z A + A\partial_z A^*
= A^*(j\gamma|A|^2 A) + A(-j\gamma|A|^2 A^*) = 0$。よって $|A(z,T)|=|A(0,T)|$ は一定。

すると右辺の $|A|^2$ も一定なので、位相だけが線形に増える:

$$ A(z,T) = A(0,T)\,\exp\!\bigl(j\,\gamma\,|A(0,T)|^2\,z\bigr). $$

**各時刻 $T$ で、その瞬時強度に比例した位相**が乗る。これがコードの `nonlinear_step`。
ピーク($T=0$, $|A|^2=P_0$)での位相変化は

$$ \boxed{\;\phi_\mathrm{max}(z) = \gamma\,P_0\,z\;} $$

で、**距離に比例**する。傾きは $\gamma P_0 = 2.1\ \mathrm{rad/km}$。$z=5$ km で $10.5$ rad。出力と一致。

**非線形長** $L_\mathrm{NL}=1/(\gamma P_0)=0.476$ km は、ピーク位相が 1 rad たまる距離の目安。

## 3. SPM スペクトル広がり(右図)

位相 $\phi(T)=\gamma|A(T)|^2 z$ は時間とともに変化するので、**瞬時周波数**

$$ \delta\omega(T) = -\frac{\partial\phi}{\partial T} = -\gamma z\,\frac{\partial|A(T)|^2}{\partial T} $$

が生じる(**チャープ**)。パルスの前縁(強度が増えるところ)では周波数が下がり、後縁では上がる。
こうして新しい周波数成分が生まれ、**スペクトルが広がる**。広がりとともに、位相の山と谷が干渉して
**多峰構造**(右図の $z=5$ km)になる。ピーク数は最大位相 $\phi_\mathrm{max}$ が大きいほど増える。
これは SPM の代表的なサインで、強度波形(時間)は変わらないのに**周波数だけが広がる**のが特徴。

> **分散との対比** — 問4-1 の分散は「強度波形が広がるが、スペクトルは不変」。本問の SPM は逆に
> 「強度波形は不変だが、スペクトルが広がる」。両者は時間と周波数で**双対**の関係にある。

## 4. 数値との一致

非線形のみの伝搬は時間領域で厳密に解ける($|A|$ 一定なので位相を足すだけ)ので、
数値と解析解は **誤差 $\sim10^{-16}$**(丸め誤差)で一致する。

## 5. コードのポイント

- `fiber.nonlinear_step(A, γ, z)` — `A * exp(jγ|A|²z)`。分散が無いので1ステップで厳密。
- ピーク位相は `angle(A[peak]·conj(A0[peak]))` を `np.unwrap` で連続化して測定($2\pi$ 巻き戻り対策)。
- 右図のスペクトルは `|fft(A)|²`。SPM で広がる様子を dB 表示。
