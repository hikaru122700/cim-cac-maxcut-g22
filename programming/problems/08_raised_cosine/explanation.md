# 問題2-2: レイズドコサイン(raised cosine)スペクトル整形

## 問題

符号速度 $R_s = 50$ Gbaud、ロールオフ係数 $\alpha = 1$ の raised cosine でスペクトル整形した
QAM サンプル列を生成する。

1. このスペクトル整形に必要な **サンプリング周波数** を考える(50 Gsample/s ではサンプリング定理を満たさない)。
2. 整形の **入力に使う系列** が何であるべきかを考える。
3. 整形サンプル列を生成し、**最初の10シンボル時間の時間波形**を図示する。
4. **ISI が生じないタイミングでサンプル抽出**したシンボル列のコンステレーションを図示する。

```
ISI確認 (16QAM): シンボル中心サンプルと元シンボルの最大誤差 = 0.00e+00
```

## 1. なぜ 1 sample/symbol では足りないのか(サンプリング周波数)

これまで(第1週)は 1 シンボルを 1 サンプルで表す **1 sample/symbol** だった。
$R_s=50$ Gbaud なら $f_s = 50$ Gsample/s。これは「シンボルが点(インパルス)」という理想化で、
実際の連続波形は表せていない。

α = 1 の raised cosine で整形すると、信号の占有帯域(複素ベースバンドの両側)は

$$ B = (1+\alpha)R_s = (1+1)\times 50 = 100\ \text{GHz}. $$

複素ベースバンド信号をエイリアスなく標本化するには、**サンプリング周波数が占有帯域以上**でなければならない
(複素信号のサンプリング定理):

$$ f_s \ge B = (1+\alpha)R_s = 100\ \text{Gsample/s} \;\Longrightarrow\; \frac{f_s}{R_s} \ge 2. $$

つまり **最低でも 2 sample/symbol** 必要。$f_s = 50$ Gsample/s(1 sps)では帯域 100 GHz を
50 Gsample/s で標本化することになり、サンプリング定理($f_s \ge B$)を満たさずエイリアシングが起きる。
本実装では最小の **2 sample/symbol**(`SPS = 2`)を採用する。

## 2. 整形の入力に使う系列(0挿入アップサンプリング)

「スペクトル整形を行う入力サンプル列」として正しいのは、
**QAMシンボル列を $sps$ 倍にアップサンプル(シンボルとシンボルの間に $sps-1$ 個の 0 を挿入)した列**である。

```python
up = np.zeros(len(sym) * sps, dtype=complex)
up[::sps] = sym          # シンボルを sps 間隔に置き、間は 0
shaped = np.convolve(up, h)   # RCフィルタ h で整形
```

なぜ 0 挿入か。連続信号 $x(t)=\sum_n s[n]\,h(t-nT)$ を標本化したものが整形サンプル列。
これは「シンボルを $T$ 間隔のインパルス列にしてパルス $h$ を畳み込む」ことに等しく、
離散では「$sps$ 間隔に 0 を挟んだ列とフィルタ係数の畳み込み」になる。
**シンボルを単純に繰り返したり線形補間したりするのは誤り**(スペクトルが変わってしまう)。

## 3. raised cosine と「ゼロ ISI(Nyquist 条件)」

raised cosine パルスの時間波形は

$$ h(t) = \underbrace{\frac{\sin(\pi t/T)}{\pi t/T}}_{\text{sinc}}\cdot
\frac{\cos(\pi\alpha t/T)}{1-(2\alpha t/T)^2}. $$

重要な性質は **Nyquist 条件**:

$$ h(0)=1,\qquad h(mT)=0\quad(m=\pm1,\pm2,\dots). $$

つまり **自分のシンボル中心では値1、他のシンボル中心では値0**。だから整形波形を
**シンボル中心 $t=nT$ でサンプルすると、隣のシンボルからの寄与が全部0になり、元のシンボル $s[n]$ がそのまま得られる**。
これが **ISI(符号間干渉, Inter-Symbol Interference)が生じないタイミング**。

出力の「最大誤差 = 0.00e+00」は、シンボル中心サンプルが元シンボルと完全一致したことの確認。
だから ISI-free サンプリング後のコンステレーション(下図)は、**雑音が無ければ整形前と同じ完全な格子**になる。

> **ロールオフ α の意味** — α は「sinc にどれだけ余分な帯域を足して時間応答の裾を速く減衰させるか」。
> α=0 は帯域最小($B=R_s$)だが裾が長く実装に弱い。α=1 は帯域が倍($B=2R_s$)になるが、
> 裾の減衰が速くタイミング誤差に強い。本問は α=1。

## 4. 時間波形の見どころ

図(16QAM, I・Q)を見ると:

- **青い連続波形**は滑らかに繋がっている(これが実際に光ファイバを伝わる電界の包絡線)。
- **赤い□(シンボル中心)**は必ず波形の上に乗り、整形前のシンボル値(±0.32, ±0.95 など 16QAM の格子値)に一致。
- **オレンジ点(2 sps サンプル)**もすべて連続波形の上にある。たった 2 sps でもこの帯域の波形を
  エイリアスなく表現できている = サンプリング定理を満たしている証拠。

## 5. コードのポイント

- `comm.rc_filter(beta, sps, span)` — raised cosine の FIR 係数(ピーク1)。`span` はフィルタ長[シンボル]。
- `pulse_shape()` — 0挿入アップサンプル → 畳み込み。群遅延 `delay = (len(h)-1)//2` を返し、
  `shaped[delay + n*sps]` が $n$ 番目のシンボル中心になる。
- `rc_pulse()` — 表示用に連続波形をアナログ再構成する(高分解能 32×)。実処理(2 sps)とは別に、
  「本当の連続波形」を描いてサンプル点と重ねるために使う。
- ISI-free 抽出: `centers = delay + arange(Nsym)*sps` のインデックスで取り出す。
