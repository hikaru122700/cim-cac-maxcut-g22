# 問題1: PRBS の生成と強度スペクトル

## 問題

光ファイバ通信で用いる **PRBS (pseudo random bit sequence, 擬似ランダムビット系列)** を生成する。
15 ビットのシフトレジスタ (LFSR) を使い、

- 各クロックでレジスタを **右に 1 ビットシフト**
- 最高次ビット **b14 を出力**
- 最低次ビット **b0 に b13 XOR b14 を入力**

この操作を `2^15 − 1 = 32767` 回繰り返すとレジスタは初期値に戻る。
すなわち **周期 32767 ビットの PRBS** が得られる。1 周期分を生成し、強度スペクトルを図示せよ。

## 実行結果(出力)

```
周期           : 32767 ビット
1 の個数       : 16384  (理論値 2**14 = 16384)
0 の個数       : 16383
先頭 32 ビット : 11111111111111100000000000000100
1 周期後に初期状態へ復帰: True
スペクトル図を保存しました: .../problems/01_prbs15/spectrum.png
```

生成された図(時間波形・平坦スペクトル・sinc² スペクトルの 3 段):

![PRBS15 の時間波形と強度スペクトル](spectrum.png)

> **図の読み方**
> - **上段**: PRBS の時間波形(先頭 100 ビット)。0/1 が不規則に並ぶ。
> - **中段**: インパルスモデルの強度スペクトル。直流以外は高さ約 1 で**平坦**=白色雑音的。
> - **下段**: NRZ 矩形パルスの強度スペクトル。線スペクトル群が **sinc² 包絡線(赤破線)**を埋め、クロック周波数の整数倍でヌルになる。

---

## 1. 仕組み — 線形帰還シフトレジスタ (LFSR)

レジスタの状態を `b0, b1, ..., b14`(b14 が出力側)とする。1 クロックの動作は次の通り。

```
出力        = b14
帰還ビット  = b13 XOR b14
シフト      = [b0..b13] を 1 つ右へ送り、空いた b0 に帰還ビットを入れる
```

つまり新しい状態は

```
b0' = b13 XOR b14   (帰還)
b1' = b0
b2' = b1
 ...
b14' = b13
```

`XOR` は「排他的論理和 = mod 2 の足し算」なので、この回路は **GF(2)(2 元体)上の線形漸化式**になっている。タップ(帰還に使うビット)は 13 と 14 の位置で、対応する **生成多項式**は

![g(x) = x^15 + x^14 + 1](eq_polynomial.png)

である。

### なぜ周期が 2^15 − 1 になるのか

15 ビットのレジスタが取りうる状態は `2^15 = 32768` 通り。ただし **全 0 状態は XOR しても全 0 のまま**で抜け出せない(禁止状態)。残る `2^15 − 1 = 32767` 通りを 1 つも欠かさず巡回できれば最大長になる。

これが起きるのは生成多項式が **原始多項式 (primitive polynomial)** のとき。
`x^15 + x^14 + 1` は GF(2) 上の原始多項式として知られており、得られる系列を **M 系列 (maximal-length sequence)** と呼ぶ。実際にプログラムでは「1 周期回すと初期状態(全 1)に戻る」ことを確認している。

> 全 0 は禁止なので、初期値は 0 以外なら何でもよい(本コードでは全ビット 1 で開始)。

---

## 2. M 系列の性質(プログラムで確認できること)

長さ `N = 2^15 − 1` の M 系列には次の性質がある。

| 性質 | 内容 | 本問での値 |
| ---- | ---- | ---------- |
| 平衡性 (balance) | 1 周期中の「1」の数は「0」の数より 1 個だけ多い | 1 が `2^14 = 16384` 個、0 が `16383` 個 |
| 自己相関 | 1 周期ずらした相関は、ぴったり一致(ずれ 0)で `N`、それ以外は `−1` | ほぼ理想的な鋭いピーク |
| ランレングス | 連続する同符号の長さの分布が乱数的 | 図(先頭 100 ビット)参照 |

平衡性とほぼ −1 一定の自己相関が、PRBS が「周期内ではランダム雑音のように見える」根拠である。

---

## 3. 強度スペクトル

「強度スペクトル」= パワースペクトル `|FFT|^2` のこと。本コードでは見方を 2 つ示している。

### (a) インパルスモデル(1 ビット = 1 サンプル)→ 平坦スペクトル

各ビットを瞬時値とみなして FFT すると、M 系列では **すべてのスペクトル線がほぼ等しい高さ**になる(直流成分だけは平衡性によりほぼ 0)。これは自己相関がほぼ δ 関数であることのフーリエ対応で、**白色雑音的に全周波数へ均一にエネルギーが広がっている**ことを意味する。図の中段が平坦になるのはこのため。

> 双極性 (0→−1, 1→+1) に変換してから FFT している。こうすると直流が消え、信号本来の広帯域成分が見やすくなる。

### (b) NRZ 矩形パルスモデル → sinc² 包絡線

実際に光ファイバを伝送するのは、各ビットを 1 ビット時間だけ保持した **NRZ 矩形パルス**波形。矩形パルス(幅 T)のフーリエ変換は sinc 関数なので、パワースペクトルの**包絡線は**

![|H(f)|^2 はsinc^2(fT)に比例](eq_sinc.png)

となり、**クロック周波数の整数倍でヌル(0)**になる。図の下段で、PRBS のスペクトル線群がちょうど sinc² 包絡線(赤破線)を埋めていることが確認できる。第 1 ヌルがクロック周波数 = 1 に来ており、信号帯域の目安になる。

(a) と (b) は矛盾しない。「白色的な多数の線スペクトル」(a)に、「パルス整形による sinc² 包絡線」(b)が掛かったものが、実際の送信スペクトルである。

---

## 4. コードのポイント

- `generate_prbs15()` — LFSR を 1 周期回して出力ビット列を返す。`reg = [feedback] + reg[:14]` の 1 行が「右シフト+帰還」を表す。最後にレジスタが初期状態へ戻ることも返す。
- `line_spectrum()` — インパルスモデルの強度スペクトル(平坦)。`np.fft.rfft` は実数入力用 FFT で計算が速い。
- `nrz_spectrum()` — `np.repeat` で各ビットを `samples_per_bit` 個に複製して矩形パルスを作り、FFT して sinc² 包絡線を得る。周波数軸はクロック周波数を 1 に正規化。
- 図は 3 段(時間波形 / 平坦スペクトル / sinc² スペクトル)で `spectrum.png` に保存。

### 実行

```bash
python solution.py
```

標準出力は冒頭の「実行結果(出力)」、生成図は `spectrum.png`(同じく冒頭に掲載)を参照。

---

## 5. 計算量

- 系列生成: `O(N)`(`N = 32767`、Python ループでも一瞬)
- FFT: `O(M log M)`(`M` はサンプル数。NRZ は `N × samples_per_bit` 点)

ビット生成は NumPy のビット演算でベクトル化も可能だが、LFSR は前の状態に依存する逐次処理のため、ここでは可読性を優先して素直なループにしている。
