# 問題4-6: 損失 + 波長分散の多中継伝送とディジタル分散補償後の BER

## 問題

問4-5 の構成に **波長分散**(損失係数 0.3 dB/km、二次分散 $\beta_2=-22\ \mathrm{ps^2/km}$)を加える。

## 1. 波長分散は「線形・可逆」

波長分散は周波数ごとに位相を回す **全域通過(オールパス)フィルタ**:

$$ H_\mathrm{CD}(\omega) = \exp\!\left(j\frac{\beta_2}{2}\omega^2 z\right),\qquad |H_\mathrm{CD}(\omega)|=1. $$

振幅は変えず位相だけ回すので、パルスは広がって ISI を生むが(下図左)、**エネルギーも情報も失われない**。
$N$ スパンで蓄積する総分散 $\beta_2\cdot(N\times100\,\mathrm{km})$ に対し、受信側で逆位相

$$ H_\mathrm{comp}(\omega) = \exp\!\left(-j\frac{\beta_2}{2}\omega^2 z_\mathrm{total}\right) $$

を掛ければ **完全に元へ戻る**(下図右)。これが **ディジタル分散補償**。コヒーレント受信は複素振幅
(位相)が取れるので、この補償が DSP で可能になる。

## 2. なぜ BER が問4-5 と一致するのか

ポイントは2つ:

1. **信号**: 分散は可逆なので、補償後は分散の無い場合と同じ QPSK に戻る。
2. **雑音(ASE)**: ASE は分散補償フィルタ(オールパス)を通っても、**白色性も電力も変わらない**
   (オールパスは白色雑音を白色のまま保つ)。だから補償後の雑音電力は問4-5 と同じ $N\cdot S_\mathrm{ASE}\cdot R_s$。

したがって SNR も BER も問4-5 と一致する:

$$ \mathrm{SNR}_N = \frac{P_\mathrm{in}}{N\,S_\mathrm{ASE}\,R_s},\qquad \mathrm{BER}=Q(\sqrt{\mathrm{SNR}_N}). $$

受信感度(BER $=10^{-3}$)は問4-5 とまったく同じ値($-13.0,\ -10.1,\ \dots,\ +4.0$ dBm)になっている。
**「波長分散は、線形である限り、補償すれば無害」**というのが本問の結論。

## 3. 数値実装の注意

本シミュレーションは 1 sample/symbol で行い、分散を**1シンボル帯域内のオールパス位相フィルタ**として
適用している(時間刻み $\Delta t = 1/R_s$ を ps に換算して $\beta_2$ と整合)。各スパンで

```
分散 → 損失 → EDFA(+ASE)
```

を適用し、最後に総分散の逆を掛ける。分散ステップ・補償ステップは線形なので、途中の ASE が
どの順で分散を受けても、最終的にオールパス変換しか受けず、雑音電力は保存される。
(実機では信号帯域 $(1+\alpha)R_s$ をカバーするため 2 sps 以上で処理するが、補償が完全という結論は同じ。)

## 4. コードのポイント

- `fiber.dispersion_step(A, β2, z, ω)` — 順方向は `z=L_span`、補償は `z=-N·L_span`。
- 補償は最後にまとめて1回(線形なので途中の順序に依らず総量だけ効く)。
- 補償前 `A_disp`(分散で崩れた信号)と補償後 `r` を保存して、コンステレーションで対比。
- BER 理論は問4-5 と同じ `Pin/(N·S_ASE·Rs)`。

## 5. この問題のつながり

ここまでは伝送路がすべて **線形**(損失・分散・ASE)で、$P_\mathrm{in}$ を上げれば BER は下がる一方だった。
最後の **問4-7** では **非線形効果**を加える。非線形は分散補償では取り除けず、$P_\mathrm{in}$ を上げすぎると
かえって BER が悪化する。その結果、**最適入力パワー**が存在することを見る。
