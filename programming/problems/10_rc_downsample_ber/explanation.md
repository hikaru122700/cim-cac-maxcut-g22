# 問題2-4: ダウンサンプリング・QAM復調・デマッピングと BER

## 問題

複素 AWGN が付加されたスペクトル整形 QAM サンプル列を、**ISI が生じないタイミングでサンプル抽出
(ダウンサンプリング)**する。得られたサンプル列に **QAM 復調(判定)+ QAMデマッピング**を行って
復調ビット系列を求め、**ビット誤り率(BER)** を計算する。

## 実行結果(出力)

```
α=1.0, 2 sps, シンボル数=500000, SNR=20.0 dB

     方式       誤りビット数       BER(整形,実測)       BER(解析解)
    4QAM            0        0.000e+00      7.620e-24
   16QAM            9        4.500e-06      2.904e-06
   64QAM        25025        8.342e-03      8.486e-03
  256QAM       262072        6.552e-02      6.517e-02
```

## 1. ダウンサンプリング(ISI-free 抽出)

「ダウンサンプリング」とは、$2$ sample/symbol の整形サンプル列から、**シンボル中心(ISI が生じないタイミング)
だけを取り出して 1 sample/symbol に戻す**こと。raised cosine の Nyquist 性により、このタイミングでは
他シンボルからの干渉が 0 なので、受信シンボルは「元シンボル + 雑音」というきれいな形になる。

```python
rx_sym = comm.downsample_isi_free(rx, delay, SPS, N_SYM)   # idx = delay + n*sps
```

## 2. 復調(QAM復調)+ デマッピング

ダウンサンプル後は第1週とまったく同じ処理:

- **QAM復調(判定)**: 各受信シンボルを最近傍コンステレーション点へ硬判定(問1-4)。
- **QAMデマッピング**: 判定シンボルをグレイ符号の逆変換でビットに戻す(問1-5)。

共通ライブラリでは `comm.symbols_to_bits` が判定とデマッピングをまとめて行う。
得られたビットを送信ビットと比べて BER を計算する。

## 3. なぜ整形しても BER が変わらないのか

これが本問の最重要ポイント。結果を見ると、**整形あり(本問)の BER は、整形なし(第1週・問1-6)や
解析解とほぼ一致**している。理由は2つの性質の組み合わせ:

1. **Nyquist 性(ゼロ ISI)**: シンボル中心では信号は元シンボルそのもの(電力1)。整形による干渉が無い。
2. **白色雑音**: AWGN は各サンプル独立なので、ダウンサンプリングで残った各サンプルの雑音電力は変わらず 0.01。

したがって判定点での受信シンボルは「元シンボル + 電力 0.01 の複素ガウス雑音」で、
1 sps のときと統計的に同一。だから BER も同じになる。

| 方式 | BER(整形あり, 本問) | BER(整形なし, 問1-6) | 解析解 |
| ---- | --- | --- | --- |
| 16QAM | $4.5\times10^{-6}$ | $2.8\times10^{-6}$ | $2.9\times10^{-6}$ |
| 64QAM | $8.34\times10^{-3}$ | $8.43\times10^{-3}$ | $8.49\times10^{-3}$ |
| 256QAM | $6.55\times10^{-2}$ | $6.55\times10^{-2}$ | $6.52\times10^{-2}$ |

(16QAM の実測がばらつくのは、BER が小さく誤り数が一桁(9個)なので統計的に揺らぐため。)

> **整形の意味は「波形」にある** — 整形は BER を改善するためではなく、**実際に送れる帯域内に信号を収め、
> 隣接チャネルへの漏れを抑え、サンプリング定理を満たす連続波形を作る**ためにある。
> 理想条件下では BER は変わらないが、帯域制限のある実システムでは整形が必須になる。

## 4. コードのポイント

- 送受信チェーン: `bits → bits_to_symbols → pulse_shape → add_awgn → downsample_isi_free → symbols_to_bits`。
- 送信ビットを基準に BER を計算(`comm.count_bit_errors`)。
- BER は対数軸の棒グラフで解析解と比較。
