# 問題4-3: 基本ソリトン(N=1)の伝搬

## 問題

波長分散と非線形効果の **双方** を考える。ソリトン次数が $N=1$ となる条件の sech パルスを伝搬させ、
**伝搬に伴い時間波形が変化しない**ことを確認する。

## 実行結果(出力)

```
β2=-22.0 ps^2/km, γ=2.1 1/(W·km), FWHM=10.0 ps
T0(sech) = 5.673 ps
N=1 のピーク強度 P0 = |β2|/(γ T0^2) = 0.3255 W
確認: ソリトン次数 N = 1.0000
分散長 L_D = 1.463 km, ソリトン周期 z0 = (π/2)L_D = 2.298 km

  z/z0  FWHM soliton [ps]       FWHM 分散のみ [ps]
     0              10.00                10.00
     1              10.00                18.88
     2              10.00                28.06
     3              10.00                37.09
     4              10.00                46.21
     5              10.00                55.46

ソリトンの FWHM 変動 = 0.00 % (ほぼ一定なら 0% に近い)
```

## 1. ソリトンとは — 分散と非線形の釣り合い

問4-1 の **分散** はパルスを広げ、問4-2 の **非線形(SPM)** は強度に応じた位相(チャープ)を与える。
**異常分散($\beta_2<0$)** のもとでは、SPM が作るチャープと分散が**ちょうど逆向き**に働き、互いに打ち消し合える。
この釣り合いが完全に成立する特別なパルスが **ソリトン(soliton)**。形が崩れずに伝わる。

支配方程式は損失を無視した非線形シュレディンガー方程式:

$$ \frac{\partial A}{\partial z} = -j\frac{\beta_2}{2}\frac{\partial^2 A}{\partial T^2} + j\gamma|A|^2 A. $$

## 2. ソリトン次数と N=1 条件

分散と非線形の強さの比を表すのが **ソリトン次数**

$$ N^2 = \frac{\gamma P_0 T_0^2}{|\beta_2|} = \frac{L_D}{L_{NL}}. $$

$N=1$(**基本ソリトン**)のとき、分散と非線形がぴったり釣り合い、**強度波形が完全に不変**になる。
条件は

$$ \boxed{\;P_0 = \frac{|\beta_2|}{\gamma T_0^2}\;}. $$

$T_0=5.673$ ps(FWHM 10 ps の sech)では $P_0 = 22/(2.1\times5.673^2)=0.326$ W。
出力で $N=1.0000$ を確認している。

基本ソリトンの厳密解は

$$ A(z,T)=\sqrt{P_0}\,\mathrm{sech}\!\left(\frac{T}{T_0}\right)\exp\!\left(j\frac{z}{2L_D}\right) $$

で、$|A(z,T)|^2$ は $z$ に依らない(位相だけが回る)。**ソリトン周期** $z_0=(\pi/2)L_D=2.30$ km は、
位相が一巡する距離(高次ソリトンが元の形に戻る周期)。

## 3. 数値による確認

`propagate_ssfm`(対称 Split-Step Fourier 法)で分散と非線形を交互に適用しながら $5z_0$($\approx$11.5 km)
伝搬させると、FWHM は **10.00 ps のまま変動 0.00%**。一方、同じパルスを**分散のみ**で伝搬させると
55 ps まで広がる(問4-1 と同じ broadening)。この対比が「非線形が分散をちょうど補償している」ことの証拠。

> **Split-Step が正しく動いている確認** — ソリトンが崩れずに伝わることは、分散ステップと非線形ステップの
> **相対符号が正しい**ことの強力な検証になっている(符号が逆だと即座に広がる/潰れる)。本ライブラリの
> `fiber.propagate_ssfm` の符号規約はこのテストに合格している。

## 4. なぜ重要か

ソリトンは「分散で広がらずに長距離を伝わる」ため、かつてソリトン通信として研究された。
現代のコヒーレント通信ではディジタル分散補償(問4-6)が主流だが、ソリトンは
**分散と非線形が独立な劣化ではなく相互作用する**ことを最も鮮やかに示す例であり、
非線形伝搬を理解する基礎になる。

## 5. コードのポイント

- `fiber.sech_pulse` / `fiber.t0_from_fwhm_sech` — sech パルス。FWHM から $T_0$ を `2\,\mathrm{arccosh}\sqrt2` で換算。
- `P0 = |β2|/(γ T0²)` — N=1 条件のピーク強度。
- `fiber.propagate_ssfm(A0, z, dz, dt, beta2, gamma)` — 対称 Split-Step。`dz=z0/200` と十分細かく。
- 比較用に `fiber.dispersion_step`(分散のみ)も計算して重ねている。
