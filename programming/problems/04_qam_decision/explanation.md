# 問題1-4: 受信 QAM サンプルの判定(decision)

## 問題

AWGN が付加された各受信サンプルについて、**参照シンボル**(マッピングに用いた
$M$ 個のコンステレーション点。例えば 16QAM なら 16 種類)から
**ユークリッド距離が最も近いシンボル**を選び、受信シンボル列を復号する。
この最近傍選択を **判定 (decision)** と呼ぶ。

## 実行結果(出力)

```
シンボル数=1000000, SNR=20.0 dB
  4QAM: シンボル誤り数=      0, SER=0.000e+00
 16QAM: シンボル誤り数=     11, SER=1.100e-05
 64QAM: シンボル誤り数=  49920, SER=4.992e-02
256QAM: シンボル誤り数= 453705, SER=4.537e-01
```

## 1. 判定(decision)= 最尤判定

AWGN は対称なガウス分布なので、「送信されたシンボルとして最も尤もらしいのはどれか」という
**最尤判定 (Maximum Likelihood)** は、**受信点に最も近いコンステレーション点を選ぶ**こと、
すなわち最近傍判定と一致する。判定は

$$ \hat{s} = \arg\min_{c \in \mathcal{C}} |r - c|^2 $$

で表される($\mathcal{C}$ は $M$ 個の参照シンボル集合、$r$ は受信サンプル)。

## 2. 方形QAMでは「軸ごとの丸め」で済む

参照シンボル $M$ 個すべてとの距離を総当たりで計算してもよいが、$10^6$ サンプル × 256 点は重い。
**方形QAMは I 軸と Q 軸が独立**なので、距離を2乗で展開すると

$$ |r-c|^2 = (r_I - c_I)^2 + (r_Q - c_Q)^2 $$

となり、I 軸と Q 軸を **別々に最も近いレベルへ丸める** だけで最近傍が求まる。
共通ライブラリ `comm.decide` は各軸を PAM レベルへ丸める方式(スライサ)で、これを $O(N)$ で行う:

```python
x = sym * qam_norm(M)                       # 整数振幅スケールに戻す
i_idx = clip(round((x.real + (L-1))/2), 0, L-1)   # I軸を最近傍レベル番号へ
q_idx = clip(round((x.imag + (L-1))/2), 0, L-1)   # Q軸を最近傍レベル番号へ
```

`round` が「最も近い格子点への丸め」、`clip` が「外周より外に出た点を端のレベルに留める」役割。

## 3. シンボル誤り率(SER)の解釈

判定結果が送信シンボルと一致しない割合が **SER (Symbol Error Rate)**。
SNR = 20 dB での結果は次のように理解できる(問1-3の最小距離 $d_{\min}=\sqrt{6/(M-1)}$ と
雑音 $\sigma\approx0.071$ の比較がそのまま効く)。

| 方式 | $d_{\min}/2$ | $\dfrac{d_{\min}/2}{\sigma}$ | 実測SER | 理論SER(方形QAM厳密式) |
| ---- | --- | --- | --- | --- |
| 4QAM | 0.71 | 10.0 | 0 | $\sim10^{-23}$(実質ゼロ) |
| 16QAM | 0.32 | 4.5 | $1.1\times10^{-5}$ | $1.0\times10^{-5}$ |
| 64QAM | 0.15 | 2.2 | $4.99\times10^{-2}$ | $5.0\times10^{-2}$ |
| 256QAM | 0.077 | 1.1 | 0.454 | 0.454 |

理論SERは、1軸あたりの誤り確率 $p = 2\!\left(1-\tfrac1L\right)Q\!\left(\sqrt{\tfrac{3\gamma_s}{M-1}}\right)$ から
$\mathrm{SER} = 1-(1-p)^2$ で計算したもの(共通ライブラリ `comm.ber_theory_qam` と同じ $Q$ 関数を使用)。
実測と理論がよく一致しており、判定が正しく実装できていることが確認できる。

判定境界までの余裕 $d_{\min}/2$ が雑音 $\sigma$ の **約4.5倍以上あればほぼ誤らない**(16QAM)が、
**同程度になると半分近く誤る**(256QAM)。これが高次QAMの難しさである。

## 4. コードのポイント

- `comm.decide(rx, M)` — 受信サンプルを最近傍コンステレーション点へ硬判定する。
- `comm.qam_constellation(M)` — 参照シンボル($M$ 個の格子点)を返す。図に赤 × で重ねている。
- `np.isclose(dec, tx)` — 判定結果と送信が一致したかの判定(浮動小数の等値比較なので isclose)。

## 5. この問題のつながり

判定で得た「最も近い参照シンボル」を、次の **問1-5** でビットに戻し(デマッピング)、
**問1-6** で送信ビットと比べて **ビット誤り率(BER)** を求める。
SER はシンボル単位、BER はビット単位の誤り率で、グレイ符号のおかげで両者は単純な比例に近い関係になる。
