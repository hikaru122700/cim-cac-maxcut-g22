# 問題2-5: スペクトル整形 QAM の BER の SNR 依存性

## 問題

スペクトル整形(α=1 raised cosine、2 sample/symbol)した QAM サンプル列に対して、
**BER の SNR 依存性**を計算してグラフにし、解析解(近似式)と比較する。
横軸 SNR [dB]、縦軸 BER(対数表示)。

## 1. 整形ありチェーンでの BER 測定

各 SNR について、問2-4 と同じ送受信チェーンを回して BER を測る:

```
ランダムビット → QAMマッピング → RC整形 → 複素AWGN → ISI-freeダウンサンプリング
              → 判定 + デマッピング → 誤り計数
```

これを SNR を変えて繰り返し、(SNR, BER) を並べると曲線になる。

## 2. 整形なし(問2-1)と同じ曲線になる理由

問2-3・2-4 で見たとおり、raised cosine は **Nyquist パルス**なので、ISI-free タイミングでの
受信シンボルは「元シンボル + 電力 $N_0$ の複素ガウス雑音」。これは 1 sample/symbol のときと統計的に同じ。
したがって BER-SNR 曲線も問2-1 とまったく同じになり、解析解

$$ \mathrm{BER} \approx \frac{4}{\log_2 M}\left(1-\frac{1}{\sqrt M}\right)
Q\!\left(\sqrt{\frac{3}{M-1}\,\gamma_s}\right) $$

によく一致する。図でも実測□が解析解の実線にきれいに乗っている。

## 3. これが意味すること

「パルス整形は BER を悪化させない(理想条件では)」という重要な結論。
整形は **帯域を制限して実際に伝送できる連続波形を作る**ためのものであり、
正しく Nyquist パルス(raised cosine)を使い、正しいタイミング(ISI-free)でサンプルすれば、
**符号間干渉ペナルティなしに**第1週と同じ性能が得られる。
逆に、タイミングがずれたり Nyquist でないパルスを使うと、ISI による BER 劣化が現れる。

- `measure_ber_shaped(M, snr, rng)` — 整形ありチェーンで1点ぶんの BER を測る。

  そのぶん測定下限 BER は少し高め($\sim10^{-5}$)。
