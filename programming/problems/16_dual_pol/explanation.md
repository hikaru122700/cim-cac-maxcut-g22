## 1. 偏波多重(PDM)とは

光は電磁波で、進行方向に直交する **2つの偏波(x, y)** を持つ。この2つは互いに直交するので、
**同じ波長・同じ帯域で独立な信号を2つ多重**できる。これを **偏波多重(PDM, Polarization-Division Multiplexing)**
といい、伝送容量がそのまま2倍になる。現代の長距離光通信(100G/400G コヒーレント)では標準技術。

データ構造としては、各時刻のシンボルを **2成分の縦ベクトル**

$$ \mathbf{s}[n] = \begin{bmatrix} s_x[n] \\ s_y[n] \end{bmatrix} $$

で表す。プログラムでは形状 $(2, N)$ の複素配列にする(1行目が x偏波、2行目が y偏波)。

## 2. y偏波を「x の遅延版」にする理由

本問では y偏波を x偏波の 1000 サンプル遅延コピーにする:

```python
x = make_symbols(M, N_SYM)      # x偏波
y = np.roll(x, DELAY)           # y偏波 = x を 1000 サンプル遅延
dual = np.vstack([x, y])        # (2, N)
```

同じ PRBS 由来でも、**1000 シンボルずらせば各時刻では無相関**になる(出力の相関 ≈ 0)。
こうすると、わざわざ別系列を用意しなくても「2偏波に独立データを載せた」状況を簡単に作れる。
出力の「x·y\* の正規化相関 = 0.0000」がその確認で、`np.roll` による遅延も
`dual[1][1000:1010] == dual[0][:10]` で検証している。

> **`np.roll` の循環シフト** — `np.roll` は端を巻き戻す循環シフト。先頭 1000 サンプルには
> 系列末尾が回り込むが、$N=10^6$ に対し 1000 はごくわずかで、統計的性質には影響しない。

## 3. これから何をするか

この (2, N) 配列が、第3週後半の出発点。実際の光ファイバを伝わると、2つの偏波は
**混ざり合う(偏波回転)**。受信側ではそれを **2×2 MIMO** でほどく必要がある。

- **問3-5**: この両偏波信号に **偏波回転**(2×2 特殊ユニタリ行列)を掛ける。
- **問3-6/3-7**: 回転・雑音・位相雑音を受けた両偏波信号を **2×2 MIMO + LMS** で等化し、BER を測る。

## 4. コードのポイント

- `np.vstack([x, y])` で $(2, N)$ 配列を作る。以降の偏波処理は、この配列に $2\times2$ 行列を掛ける
  形(`M @ dual`)で書ける。
- 平均電力が x/y とも 1.0 であることを確認(規格化が保たれている)。
- `np.vdot(x, y)` は $\sum x^*y$(共役内積)。相関の確認に使う。
