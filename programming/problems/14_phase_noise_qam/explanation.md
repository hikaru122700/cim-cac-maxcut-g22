# 問題3-2: レーザ位相雑音を付加した QAM のコンステレーション

## 問題

**1 sample/symbol**、符号速度 32 Gbaud で QAM(QPSK / 16QAM / 64QAM)シンボル列を生成する
(シンボル数 $10^6$)。コヒーレント受信を考え、線幅 $\Delta f = 10$ kHz(**前問の 100 kHz とは別の値**)の
レーザ位相雑音を付加し、コンステレーションを示す。

## 実行結果(出力)

```
符号速度 Rs = fs = 32 Gbaud, 線幅 df = 10 kHz, シンボル数 = 1000000
位相増分の分散 σ_PN^2 = 1.96e-06 rad^2
系列全体での位相のばらつき ≈ √(N)·σ_PN = 1.40 rad

QPSK (4QAM)   : 位相 θ の範囲 = [-2.84, -1.40] rad
16QAM         : 位相 θ の範囲 = [-3.68, 0.40] rad
64QAM         : 位相 θ の範囲 = [1.65, 2.90] rad
```

## 1. コヒーレント受信と位相雑音

**コヒーレント受信**では、受信した光信号を局部発振レーザ(LO)と干渉させて複素振幅(I/Q)を取り出す。
このとき送信レーザと LO レーザの位相揺らぎが受信信号に乗る。両者を合わせた **レーザ位相雑音** $\theta[n]$ は、
問3-1 と同じランダムウォークで、受信シンボルは

$$ r[n] = s[n]\cdot e^{j\theta[n]} $$

となる。$e^{j\theta}$ は **複素平面上の回転**なので、シンボルの**振幅は不変、位相だけが時間とともにふらつく**。

```python
theta = comm.laser_phase_noise(N_SYM, DF, RS, rng)   # 1 sps なので fs = 符号速度
rx = tx * np.exp(1j * theta)
```

## 2. なぜ「円弧」に広がるのか

$\theta[n]$ はゆっくりしたランダムウォーク。1 sps・32 Gbaud・$\Delta f=10$ kHz では、
1サンプルの位相ステップは $\sigma_{PN}=\sqrt{2\pi\Delta f/f_s}\approx 1.4$ mrad とごく小さいが、
$10^6$ サンプルかけて累積すると、系列全体では

$$ \sqrt{N}\,\sigma_{PN} = \sqrt{10^6}\times1.4\,\text{mrad} \approx 1.4\ \text{rad} $$

も漂う(出力と一致)。コンステレーションは全シンボルを重ねて描くので、各格子点は
**$\pm$ 数十度にわたって回転した跡**として円弧状に見える。半径 $\rho$ の点の弧長は $\rho\times(\text{角度の広がり})$
なので、**外側の点ほど弧が長く**なる。これが図で外周ほど大きく崩れている理由。

## 3. なぜ位相雑音が QAM の大敵か

- **QPSK** は位相だけで情報を運び、判定境界(象限の境)まで $45^\circ$ の余裕がある。1.4 rad ($\approx80^\circ$)も
  漂うと象限をまたいで誤るが、それでも比較的頑健。
- **高次QAM**(16/64QAM)は **振幅にも情報**を持ち、内側と外側のリング間隔が狭い。わずかな回転でも
  外周の点が隣のリング・隣の点の領域に入り込み、判定できなくなる。図で 64QAM が同心円状に
  つぶれているのは致命的で、**このままでは復調不能**。

したがって、コヒーレント受信では位相雑音を**補償(キャリア位相回復, carrier phase recovery)**しなければならない。
その代表的手法が次問の **適応等化(LMS を用いた MIMO)** であり、位相回転を逐次追従して打ち消す。

> **線幅 10 kHz vs 100 kHz** — 前問は 100 kHz だったが本問は 10 kHz。線幅が小さいほど位相は
> ゆっくり漂う(σ_PN が小さい)ので、補償しやすい。実際のコヒーレント用狭線幅レーザは
> 数 kHz〜数十 kHz 級。

## 4. コードのポイント

- 1 sample/symbol なので、サンプリングレート $f_s$ は符号速度 32 Gbaud に等しい。
  `comm.laser_phase_noise(N_SYM, DF, RS, rng)` の `fs` に符号速度を渡している。
- `rx = tx * np.exp(1j*theta)` — 各シンボルを $\theta[n]$ だけ回転。AWGN は本問では加えていない
  (位相雑音単独の効果を見るため)。
- 図は先頭 6000 点を散布図に。全 $10^6$ 点だと真っ黒になる。
