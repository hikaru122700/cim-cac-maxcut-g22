## 1. 何が変わったか — 非線形は補償できない

問4-6 までは、伝送路がすべて **線形**(損失・分散・ASE)だった。線形なら $P_\mathrm{in}$ を上げるほど
SNR が上がり、BER は単調に下がる(破線)。

非線形効果(SPM、および分散と相互作用する **チャネル内 FWM/XPM**)は **強度に依存する位相ひずみ**を生む。
これは波長分散と違って **線形フィルタでは元に戻せない**(分散補償しても残る)。しかも強度の2乗・3乗で効くので、
$P_\mathrm{in}$ を上げるほど急激に悪化する。

## 2. 最適入力パワー(U字曲線)の物理

BER は2つの競合する効果で決まる:

| パワー | 支配要因 | BER |
| --- | --- | --- |
| **低い** | ASE 雑音($\mathrm{SNR}=P_\mathrm{in}/(N S_\mathrm{ASE}R_s)$) | 信号が雑音に埋もれ **高い** |
| **高い** | 非線形ひずみ($\propto \gamma P_\mathrm{in} L_\mathrm{eff} N$) | ひずみが増えて **高い** |
| **最適** | 両者が釣り合う | **最小** |

この谷が **最適入力パワー(optimum launch power)**。図のとおり、スパン数が増えるほど

- 最適パワーは(非線形が累積するので)**上げられず頭打ち**(本問では約 0 dBm に収束)、
- 達成できる **最小 BER は悪化**(10→20→50 スパンで $1.6\times10^{-4}\to6.8\times10^{-3}\to6.8\times10^{-2}$)。

これが「光ファイバの**非線形シャノン限界**」と呼ばれる、長距離光通信の根本的な容量制限である。
線形なら無制限にパワーを上げて距離を稼げるが、非線形のせいでそれができない。

> **有効長 $L_\mathrm{eff}$** — 損失で強度が下がるため、非線形が効くのはスパン前半だけ。
> $L_\mathrm{eff}=(1-e^{-\alpha L})/\alpha = 14.5$ km(100 km スパンのうち実質これだけ)。
> 1スパンの非線形位相係数 $\gamma L_\mathrm{eff}=30.4$ rad/W は、1 W 入れると 30 rad 回る強さを意味する。

## 3. 数値解法:Split-Step Fourier 法

非線形シュレディンガー方程式

$$ \frac{\partial A}{\partial z} = -\frac{\alpha}{2}A - j\frac{\beta_2}{2}\frac{\partial^2 A}{\partial T^2} + j\gamma|A|^2 A $$

は解析的に解けない(分散と非線形が混ざる)ので、**Split-Step Fourier 法**で解く。微小区間 $dz$ ごとに

```
半分の分散(周波数領域) → 全部の非線形+損失(時間領域) → 半分の分散(周波数領域)
```

を繰り返す(対称split-step、`fiber.propagate_ssfm`)。分散と非線形を**交互に分離**して各々を厳密に適用する。

### 実装上の2つの簡略化(明記)

1. **無雑音伝搬 + 受信端 ASE ローディング**: ASE を伝搬中に加えると信号-ASE 間の非線形混合が起きるが、
   これは2次的なので、本問では「信号を無雑音で非線形伝搬 → CD補償 → 受信端で問4-6 と同じ ASE を付加」とした。
   これにより **線形項(損失・分散)は問4-6 と完全に一致**し、差分が純粋に**信号-信号間の非線形ひずみ**になる。
2. **平均非線形位相の除去**: SPM はコンステレーション全体を一定角だけ回す(決定論的)。これは実機の
   **キャリア位相回復**で除かれるので、データ援用で1つだけ取り除いてから判定している
   (除かないと QPSK の 90° 対称性で BER が見かけ上ふらつくため)。残るのが本質的な**非線形位相雑音・ひずみ**。

## 4. コードのポイント

- `fiber.propagate_ssfm(A, L, dz, dt, beta2, gamma, alpha)` — 対称 Split-Step。スパンごとに損失込みで伝搬し、
  スパン末に EDFA 利得 $\sqrt G$ を掛ける(雑音は受信端でまとめて付加)。
- 波形は sps=2・RC(α=0.1)で整形し、平均電力を $P_\mathrm{in}$ に正規化(非線形強度が正しく決まる)。
- 受信端で総分散補償 → ISI-free 抽出 → 平均位相除去 → ASE 付加($\mathrm{SNR}=P_\mathrm{in}/(N S_\mathrm{ASE}R_s)$)→ 判定。
- 破線(線形=ASEのみ)を重ねて、非線形ペナルティと最適パワーを可視化。

### 実行

```bash
python solution.py
```

(各 Pin・各スパン数で Split-Step を回すため、実行に数十秒かかる。)

## 5. 第4週(と演習全体)のまとめ

第4週では、光ファイバ伝搬の物理を順に積み上げた:

- **波長分散**(問4-1):線形・可逆、パルスを広げる($T\propto\sqrt{1+(z/L_D)^2}$)。
- **非線形 SPM**(問4-2):位相を強度で回し、スペクトルを広げる($\phi=\gamma P_0 z$)。
- **ソリトン**(問4-3):分散と非線形が釣り合うと形が崩れない。
- **EDFA/ASE**(問4-4):増幅は ASE 雑音を伴い、BER の Pin 依存性を決める。
- **多中継**(問4-5):ASE が累積し、$N$ スパンで SNR は $1/N$。
- **分散補償**(問4-6):線形分散は補償すれば無害。
- **非線形限界**(問4-7):非線形は補償できず、**最適入力パワー**と**距離による BER 限界**を生む。

演習全体を通して、**ビット → QAM変調 → パルス整形 → 光ファイバ伝搬(分散・非線形・雑音)→ コヒーレント受信
→ DSP(位相回復・MIMO・分散補償)→ 判定・BER 評価**という、現代の光ディジタルコヒーレント通信の
送受信系を端から端まで Python で構築した。各段の理論(解析解)と数値が一致することを各問で確認している。
