# プログラミング演習問題

Python の演習問題集。問題ごとに `problems/` 配下のフォルダにまとめています。

## ディレクトリ構成

```
programming/
├─ README.md              # このファイル(問題一覧の索引)
└─ problems/
   └─ NN_問題名/
      ├─ solution.py      # 解答コード
      └─ explanation.md   # 解説
```

## 問題一覧

| No. | 問題名 | カテゴリ | 解答 | 解説 |
| --- | ------ | -------- | ---- | ---- |
| 01  | PRBS の生成と強度スペクトル | 信号処理 / 光通信 | [solution.py](problems/01_prbs15/solution.py) | [explanation.md](problems/01_prbs15/explanation.md) |

## 使い方

各問題フォルダで解答を実行できます。

```bash
python problems/NN_問題名/solution.py
```
