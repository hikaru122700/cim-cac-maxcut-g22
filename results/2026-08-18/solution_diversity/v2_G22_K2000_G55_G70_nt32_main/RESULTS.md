## 1. 問いと結論の要約

**問い**: CIM は他のソルバと比べて「どれくらいバラバラの解」を出すのか。その多様性は
本物（別の谷を見つけている）なのか、単に収束していないだけなのか。

**結論**:

1. **6 手法の中で見れば、CIM はむしろ多様性の低い側**（4 インスタンスの平均順位 4.25 / 6 位。3.1.1）。
   CIM が上位に来るのは疎で小さい G22 だけで（2 位、距離 0.327、固定頂点わずか 0.8%）、
   K2000 で 4 位、G55 で 5 位、**G70 では 6 位＝最も凝集する**。一貫して多様なのは PT-ICM（平均 1.75 位）、
   一貫して凝集するのは dSB（5.75 位）。「CIM＝バラバラな解を出す」は G22 に限った現象である。
2. **ただし多様性と品質はおおむね逆行する**。「平均 gap が大きい手法ほど解が散らばる」傾向が
   4 インスタンスすべてで見られる（手法 6 点での Spearman ρ = 0.94 / 0.94 / 0.66 / 0.83、
   G22・K2000 は p = 0.005、G70 は p = 0.042、G55 は p = 0.16 で有意ではない）。CIM の多様性は
   **上位解の周辺ではなく、やや外側の広い領域に散っている**（G22 で上位 25% に CIM の解は 0 本）。
3. **それでも「収束不足のゆらぎ」ではない**。全手法の出力を**共通の Tabu Search で磨く**対照実験を
   行っても、平均距離はほとんど動かない（CIM K2000: 0.446 → 0.444、dSB: 0.313 → 0.318）。
   磨きは品質を大きく改善する（CAC K2000: gap 26.1% → 2.1%）のに距離は残る。
   **各手法は構造的に別々の場所へ着地している**。
4. **多様性の意味はインスタンスの構造で反転する**。疎な G22 は強い big valley（上位解どうしの距離が
   0.07 しかない）なので「多様＝上位解から離れている＝損」。一方、密な K2000 では
   **上位 25% の解ですら互いに 0.30〜0.37 離れている**（高品質解が多数縮退）ので、多様性は探索資源として意味を持つ。
5. **手法間でも領域が違う**。G22 で PT-ICM はどの手法からも 0.37〜0.39、CIM は 0.30 離れており、
   dSB/GA/CAC の 3 手法が互いに 0.18〜0.21 で固まっているのと対照的。
   ポートフォリオで「別の場所を見る係」は CIM と PT-ICM が担えるが、その場所の品質は低い。

## 2. 実験設定

### 2.1 対象

- 手法（6）: CIM / CAC / SA / SB(dSB) / PT-ICM / GA(memetic)。実装・パラメータは
  `scripts/benchmarks/algo_registry.py`（`results/anytime_tuned_params.json` の Optuna 調整値を適用）。
- インスタンス（4）: G22（n=2000, 疎, 非重み）, K2000（n=2000, 密, ±1 重み）,
  G55（n=5000, 疎）, G70（n=10000, 疎）。
- **独立シード 32 本**（seed = 0..31）を 1 バッチで実行し、返ってきた解ベクトルを全保存。

### 2.2 実時間を揃える

多様性は計算時間に強く依存するので、手法間で**バッチ実時間を揃える**。予算グリッド
（`BUDGET_GRIDS`）を昇順に走らせ、**目標秒を超える直前の予算を採用**した
（目標: G22 20 s / G55・G70 30 s / K2000 120 s）。採用予算と実測時間は表 1 に併記。
実時間は G22 で 7.6〜15.6 s、K2000 で 61〜159 s の範囲に収まっている
（PT-ICM の K2000 だけは最小予算でも 159 s 掛かるため超過）。

### 2.3 指標

MAX-CUT の解は分割なので、**全体反転 $s \to -s$ は同一解**。すべての距離はこの対称性を畳む:

$$d(a,b) = \frac{\min\big(H(a,b),\, n - H(a,b)\big)}{n} \in [0, 0.5]$$

- **平均ペアワイズ距離**: 32 本から作る 496 ペアの平均。0 = 全部同じ解、0.5 = 無相関（下記 2.4 に手順）。
- **相異なる解の個数**: 全体反転を同一視した上での相異なる分割の数。
- **固定頂点の割合**: 最良解に揃えた上での磁化 $m_i$ が $|m_i| \ge 0.9$ の頂点の割合。
  「どの試行でもほぼ同じ側に決まる」骨格の大きさ。
- **エントロピー**: 頂点あたりの平均二値エントロピー [bit]。1 bit = 完全にランダム。
- **1-opt 局所最適率**: 出力解のうち「1 頂点反転で改善できない」ものの割合。
- **FDC**: 見つかった最良解からの距離と gap の相関係数（big valley の強さ）。

実装: `scripts/benchmarks/diversity_metrics.py`。

### 2.4 平均ペアワイズ距離の計算手順

1. **解の収集**: 1 手法 × 1 インスタンスにつき、シード $0, 1, \ldots, 31$ の $T = 32$ 本を 1 バッチで実行し、
   返ってきた解ベクトルを $s^{(1)}, \ldots, s^{(T)} \in \{0,1\}^n$ として保存する
   （各モジュールの返り値は bool / $\pm 1$ / 0-1 とまちまちなので `> 0` で 0/1 に統一。`to_binary`）。
2. **ハミング距離**: 順序を区別しないすべてのペア $i < j$（$\binom{32}{2} = 496$ 組）について

$$H_{ij} = \sum_{v=1}^{n} \mathbb{1}\left[ s^{(i)}_v \neq s^{(j)}_v \right]$$

   実装は 0/1 行列 $X$ に対する行列積 $H = X(\mathbf{1}-X)^{\mathsf{T}} + (\mathbf{1}-X)X^{\mathsf{T}}$ で一括計算する（`hamming_matrix`）。
3. **全体反転の同一視**: MAX-CUT の解は分割なので $s$ と $\mathbf{1}-s$ は同じ解。そこで

$$d_{ij} = \frac{\min\left( H_{ij},\ n - H_{ij} \right)}{n}$$

   と折り返す（`distance_matrix`）。値域は $[0, 0.5]$。
4. **平均**: 上三角のみ（$i < j$）を取り、自己ペア $i = j$ を除いて単純平均する。

$$\overline{d} = \frac{1}{\binom{T}{2}} \sum_{i < j} d_{ij}, \qquad \binom{32}{2} = 496 \ \text{組}$$

   `summarize()` の `mean_pairwise` がこの値。中央値・最小・最大も同じ 496 個から取る
   （`median_pairwise` / `min_pairwise` / `max_pairwise`、箱ひげ図もこの 496 点を描いている）。

補足:

- **手法間距離**（3.2 のヒートマップ非対角）は 2 つの集合 $A, B$ の**全組み合わせ** $32 \times 32 = 1024$ 組の
  平均（`cross_distance_matrix`）。対角は上の手法内平均（496 組）なので、対角と非対角で組数が異なる。
- **部分集合に絞った距離**（`near_mean_pairwise`、上位 25% の平均距離）は、条件を満たす解だけを抜き出してから
  同じ手順を適用する。
- **ランダム分割どうしの基準値**: $H \sim \mathrm{Binomial}(n, 1/2)$ なので $\min$ で折り返した期待値は
  $0.5 - \sqrt{1/(2\pi n)}$ となり、厳密には 0.5 をわずかに下回る
  （実測: $n$=2000 で 0.491、5000 で 0.494、10000 で 0.496）。図中の 0.5 の線は**上限**を示すもの。
- 相異なる解の個数は、先頭要素が 0 になるよう反転を揃えて（`canonicalize`）から一意な行を数える。

## 4. 考察

### 4.1 CIM の多様性はどこから来るか

CIM は各ラウンドで全パルスに独立ガウス雑音を注入し、**best-over-rounds のスナップショット**を返す。
局所探索を一切持たないので、着地点は「増幅過程のどの分岐に乗ったか」で決まる。
結果として G22 では固定頂点が 0.8% しかない＝**共通の骨格をほとんど持たない**。
これは SA（低温で局所最適に固まる）や GA（プールが収束して 43.5% の骨格を共有する）と対照的で、
「アニールして 1 点に落とす」タイプではなく「毎回ゼロから別の分岐へ落ちる」タイプであることを示す。

一方、大規模疎（G55/G70）で CIM がむしろ最も凝集する（0.381〜0.387）のは、
物理パラメータが G22 用に調整されたものの流用で、増幅過程が**次数の大きい頂点から先に決まる
同じ順序**を辿りやすいためと考えられる（固定頂点率自体は 0.1〜1.3% と低いので、
「強い骨格がある」のではなく「散らばりの幅が他手法より狭い」）。これはパラメータ再調整で
変わりうるので、**インスタンス横断の一般則としては主張できない**。

### 4.2 「多様性」を評価するときの落とし穴

表 1 の Spearman ρ = 0.66〜0.94（うち有意なのは 3/4 インスタンス）が示す通り、
**素の多様性は品質の裏返しをかなりの部分含む**。
極端な例が K2000 の CAC（gap 26.1%、距離 0.473）で、これは「多様」ではなく「まだ何も解けていない」。
したがって多様性の主張には最低限、

1. 実時間を揃える（本実験の 2.2）、
2. 共通の局所探索で磨いた後にも残るかを見る（3.3）、
3. 上位解に絞って測る（3.4）、

の 3 点セットが要る。この 3 つを通した後でも CIM の距離は残る（G22 で 0.332、K2000 で 0.444）ので、
**CIM の多様性自体は本物**と言ってよい。問題はその多様性が置かれている品質帯である。

### 4.3 ハイブリッド／ポートフォリオへの含意

過去実験（2026-06-19 の `maxcut_algo_combo`、および Q3 の「CIM 解で GA 初期集団を代用しても
到達上限は上がらない」）と本結果は整合する。

- **G22 のような疎で big valley が強いインスタンス**: 上位解は互いに 0.07 しか離れていない狭い谷に
  集中している。CIM が供給する 0.33 離れた解はその谷の外にあり、GA の初期集団に入れても
  交叉の材料として上位解に届かない。**多様性を足しても意味が無い構造**。
- **K2000 のような密インスタンス**: 上位解自体が 0.35 離れて縮退しているので、
  多様性は原理的には資源になる。しかし CIM の生出力は gap 3.2%（磨いても 1.6%）で、
  上位帯（dSB 0.52% / GA 0.37%）に遠く届かない。**資源として使うには品質が足りない**。
- 逆に **PT-ICM は「どの手法からも 0.37 以上離れた領域」を安定して供給する**唯一の手法で、
  低予算での品質は悪いが、時間を与えたときの探索先の重複が最も少ない。ポートフォリオの
  多様性要員としては CIM より PT-ICM の方が筋が良い可能性がある（要検証）。

### 4.4 副産物: 出力が 1-opt 局所最適かどうか

本実験の副産物として、各手法の出力が「1 頂点反転で改善できない」状態かを測った。
SA・dSB・GA はほぼ常に局所最適、CIM は疎グラフでは 62〜88% が局所最適だが
**密な K2000 では 0%**（平均 37 頂点が改善可能で、TS を 20000 反復かけると gap 3.2% → 1.6%）。
**密インスタンスで CIM を使うなら、出力に軽い 1-opt を掛けるだけで gap が半減する**。
これは実装コストがほぼゼロの改善余地である。

## 5. 限界と注意

- **CIM/CAC の物理パラメータはインスタンス別調整が前提**（`results/anytime_tuned_params.json`）。
  K2000 は調整済みだが G55/G70 は G22 の定数流用 + coupling のみ調整なので、
  これらでの CIM の挙動（4.1 の凝集）はパラメータ依存の可能性が高い。
- **予算の刻みが粗い**ため、実時間は完全には揃っていない（G22 7.6〜15.6 s、K2000 61〜159 s）。
  特に PT-ICM の K2000 は最小予算でも目標 120 s を超えている（159 s）。
  これは PT-ICM に有利な方向のズレなので、「PT-ICM が多様」という結論を弱めない。
- **32 シード**は距離分布の平均を見るには十分だが、上位 25% 部分集合（数本〜数十本）の
  平均距離は誤差が大きい。厳密な主張には試行数を増やす必要がある。
- G55/G70 は全手法が未収束（gap 0.3〜4.1%）の領域での比較であり、
  「収束後の解の多様性」ではなく「同じ短い時間での着地点の多様性」を測っている。
- 磨き用 TS の 20000 反復は G22/K2000 には十分だが、G55/G70 では改善を見つけられず
  ほぼ恒等写像になっている（移動距離 ≈ 0）。この 2 インスタンスの 3.3 の行は情報量が無い。
