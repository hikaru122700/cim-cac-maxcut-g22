# GA の初期集団を CIM で作る利点：集団サイズを全問題 N = 10 にそろえた再実験

実験日: 2026-11-09 / グラフ: **G22・G55・G70**
再現コード: `scripts/benchmarks/ga_cim_timing.py --pop-size 10` → `scripts/benchmarks/ga_equal_time.py --pop-size 10 --tag main` → `scripts/benchmarks/ga_equal_time_analysis.py`
データ: `results/2026-11-09/ga_equal_time/v1_G22_G55_G70_nt16_k4_eval300_pop10_main/`(時間は `results/2026-11-09/ga_cim_timing/v1_G22_G55_G70_rep3_pop10/`)

---

## 1. この実験で何を試したか(一言で)

> 前回(`2026-10-19/ga_equal_time/v2_…_main`)は集団サイズ N を問題ごとに Optuna で調整した値(G22 15、G55 6、G70 8)を使った。
> 問題ごとの調整に頼らないよう、全問題 N = 10 にそろえて同じ比較をやり直した。
> G70 では CIM 初期集団が引き続き有意に良い。G55 は良い傾向だが弱まり(p = 0.035、Holm 補正後 0.07)、G22 は差なし。

## 2. 数式の変更点

なし。GA・CIM の更新は前回と同じ。変えたのは集団サイズ(と、それに応じた K = 4N = 40、測り直した時間)だけ。
GA の他のパラメータ(ts_iters・cr・alpha_tenure・beta_quality)は前回と同じ(`results/anytime_tuned_params.json` の値)。

## 3. 実験条件

| 項目 | 値 |
|---|---|
| 集団サイズ N | 10(3 問題共通) |
| CIM の解の数 K | 4N = 40(CIM 4800 ラウンド、G55 は 9600) |
| 条件 | ランダム / CIM(選別なし、先頭 N 個)/ CIM+カット値(上位 N 個)/ CIM+カット値+距離(上位 2N 個から貪欲) |
| 試行 | 各 16、GA の seed は 4 条件で共通 |
| 総時間 T | K·t_cim + t_init + 300·t_gen(1 スレッド CPU 時間):G22 20.2 秒、G55 55.3 秒、G70 46.8 秒 |
| 進められる世代数 | 選別なし 1251 / 3807 / 4603、選別あり 300、ランダム 1587 / 5121 / 4985 |
| 検定 | CIM(選別なし) < ランダム:片側 Mann–Whitney、3 問題で Holm |

## 4. 結果(c = 1、BKS との差の平均 %)

| 問題 | ランダム | CIM | CIM+カット値 | CIM+カット値+距離 | p(CIM < ランダム) | Holm 補正後 |
|---|---|---|---|---|---|---|
| G22 | 0.017 | 0.006 | 0.007 | 0.006 | 0.80 | 0.80 |
| G55 | 0.359 | **0.279** | 0.507 | 0.597 | 0.035 | 0.070 |
| G70 | 0.835 | **0.563** | 0.667 | 0.867 | 7.4e-7 | 2.2e-6 |

前回(N 調整済み)との比較:

| 問題 | 前回 N | 前回 ランダム / CIM | 前回 p | 今回 ランダム / CIM | 今回 p |
|---|---|---|---|---|---|
| G22 | 15 | 0.014 / 0.006 | 0.55 | 0.017 / 0.006 | 0.80 |
| G55 | 6 | 0.503 / 0.316 | 1.1e-5 | 0.359 / 0.279 | 0.035 |
| G70 | 8 | 0.861 / 0.609 | 5.1e-6 | 0.835 / 0.563 | 7.4e-7 |

## 5. 読み取り

- G70 は N によらず CIM 初期集団が良い。
- G55 は N = 10 でランダム側が大きく良くなり(0.50% → 0.36%)、差が縮んだ。N = 6 はランダム側に不利だった可能性がある。
- カット値や距離で選別すると悪くなる結果は N = 10 でも同じ(G55・G70)。選別は CIM を 4N 本分払うため GA の世代が減る。

## 6. 注意

- `ga_equal_time_analysis.py` の "Mean of empty slice" の警告は、時間の推移の図(curves)で、まだ解がない早い時刻の値が NaN になるためのもの。検定・棒グラフには影響しない。
- 時間は今回測り直したので、前回と t_cim などが少し違う(G22 の t_cim 0.58 秒 → 0.41 秒)。
