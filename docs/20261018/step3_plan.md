# ステップ 3（G-set 10 問題）：実行と判定の計画

記録日：2026-10-18。実行前にコミットして固定する。

前提：[事前登録](prereg_eigen_v1.md) の R1〜R4 の結果と、[ステップ 2](step2_dev_decisions.md) の結果。

## これまでにわかっていて、計画に反映したこと

1. **SA の開始温度で結果が変わる。** G22 の R1（開始温度 2.0）では E が再現した。調整済みの温度（4.21、R2）では、cut で説明できない差そのものが予算 1e7 で消えた（信頼性 ≈ 0）。G55 の R4（開始温度 2.0）でも、5000 掃引では差が消えた（信頼性 0.07）。一方 500 掃引では残った（0.68）。SA が種から遠く離れる設定では、種の違いが効かなくなる。
2. **warm SA は「途中の最良状態」に初期解を含めて返す。** 開始温度が高く予算が短いと、出力が初期解のままになる（G55・G70 の 50 掃引）。このときは C1 を判定できない（ラベル = 初期 cut）。
3. **小規模問題では、局所的な指標と試し打ちが安定して効き、固有ベクトル指標は問題によって効き方が違う**（±1 重みではほぼ効かない）。

そこで、開始温度を 2 つ（0.5 と 2.0）にし、試し打ち（50 掃引の SA を 2 回）を指標に加える。

## 問題と CIM

G1, G14, G15（800 頂点）、G22, G23, G32, G39（2000 頂点）、G55（5000）、G70（10000）、G77（14000）。種類は、ランダム（G1, G22, G23, G55, G70）、平面（G14, G15, G39）、トーラス（G32, G77）。重みは G32, G39, G77 が ±1、ほかは 1。

- CIM は 2400 ラウンド（全問題で収束を確認済み）。パラメータは `algo_registry.py` の値（新しい 7 問題は coupling だけを CIM 単体の平均 cut で選んだ）。
- 候補 K=512、CIM seed 1000〜1511（事前登録の実行と重ならない）。
- **注意：** G15 と G39 では、CIM の出力がほぼ同じ状態に集まる（予備測定で 32 run 中 1〜2 状態）。この 2 問題では C1 を判定できない可能性が高い。その場合は「CIM の出力が 1 つに集まるので選別の余地がない」という結果として報告する。

## SA とラベル

- 開始温度 0.5 と 2.0（終了温度 0.001）。予算は 50・500・5000 掃引（反転提案数 = 掃引 × n）。各候補に R=16 回。SA の乱数オフセット 6,000,000（0.5）と 7,000,000（2.0）。
- 試し打ち：各候補に 50 掃引の SA を 2 回（ラベルとは別の乱数）。平均と最大を指標にする。

コマンド（`NUMBA_NUM_THREADS=24`）：

```
python scripts/benchmarks/seed_value_pilot.py --dataset <G> --candidates 512 --cim-rounds 2400 --cim-seed-start 1000 \
  --sa-seed-offset <6000000|7000000> --t-start <0.5|2.0> --budgets <50n> <500n> <5000n> --trial-runs 2 --trial-sweeps 50 --tag S3
```

## 解析（`scripts/benchmarks/gset_seed_analysis.py`）

問題 × 温度 × 予算ごとに：

- **C1：** (初期 cut, LS 後 cut) で回帰した残差の split-half 信頼性（Spearman-Brown 補正）。0.3 以上かつ 95% 区間の下限 > 0 で「差あり」。
- **C2：** 次の指標と残差の Spearman ρ と 95% 区間（候補ブートストラップ）。E（eig_diff）、eig_a1、eig_a2、n_gain_minus2_to_0、ls_n_gain_minus2_to_0、n_zero_gain、ls_n_zero_gain、trial_sa_mean、trial_sa_max。

### 判定（固定）

| 番号 | 内容 | 基準 |
|---|---|---|
| H3a | C1 は、CIM の出力が多様な問題（異なる状態が候補の半分以上）で、開始温度 0.5 のいずれかの予算で成り立つ | 該当する問題の数を報告する |
| H3b | E は、開始温度 2.0・5000 掃引で、C1 が成り立つ問題で ρ > 0（R1 の一般化） | 問題ごとに区間の下限 > 0 かを報告する |
| H3c | 試し打ち（trial_sa_mean）は、C1 が成り立つ問題・条件で ρ > 0 | 同上 |
| H3d | ls_n_gain_minus2_to_0 は、C1 が成り立つ問題・条件で ρ < 0（ステップ 2 の向き） | 同上 |

各指標について、問題をまたいだ要約として「C1 が成り立つ条件のうち、区間が予想の向きで 0 を超えた割合」を出す。指標間の比較は記述にとどめる（多重比較の補正はしない）。
