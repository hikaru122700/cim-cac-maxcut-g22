## 検証用で確かめる仮説（固定）

主ラベルは 10 掃引の成功率。各仮説は 95% 区間が 0 をまたがなければ「確認」とする。3・30 掃引の結果も併記する（探索的）。

| 番号 | 内容 | 向き |
|---|---|---|
| T1 | eig_a1 は同じ cut の候補の中でラベルを予測する | τ > 0 |
| T2 | eig_diff（事前登録の E）も予測する | τ > 0 |
| T3 | 厳密量（経路長・最適解までの距離・障壁）は予測する | τ < 0 |
| T4 | eig_a1 は最適解までの距離と対応する（仕組みの確認。ラベルの代わりに最適解までの距離を使って同じ解析をする） | τ < 0 |
| T5 | 局所的な指標・試し打ちも予測する（ls_gain、ls_n_gain_minus2_to_0、試し打ち） | 順に τ > 0、< 0、> 0 |

## 開発用の結果から読み取ったこと（検証前の解釈）

- 同じ cut の候補の価値は、最適解までの距離（経路長）でほぼ決まる。障壁はそれより弱い。小規模問題では、cut を下げずに最適解に行ける候補が多い（障壁 > 0 は候補の 0〜29%）。
- eig_a1 は最適解までの距離と強く対応する（τ=−0.65）。最適解が u1 の符号に近いので、u1 に揃っている候補は最適解に近い。
- G22 の R1（予算 1e7）では、a2 の寄与のほうが大きかった（ρ(a1)=0.49、ρ(a2)=−0.60）。小規模問題で a1 が主に効くことと、仕組みが同じかは G-set（ステップ 3）で確かめる。
