# G22・G55・G70のグラフ構造評価とCIM候補評価への接続

調査日: 2026-09-21。ユーザーの補足「グラフ構造自体を評価したい」を主対象とする。確認したリポジトリHEADは9053ca4（2026-09-14）。本稿は文献調査と入力グラフの構造計算であり、GA/SAの追加性能実験や学習モデルの実装はしていない。

グラフ構造から探索法との相性を予測する先行研究として、まずMQLibが直接的である。構造指標の根拠として、Max-Cutの分解、スペクトル、疎グラフ上の局所探索の研究を組み合わせる。Transformerにはグラフ構造の表現学習とMax-Cut探索の実績がある。ただしグラフGだけの評価値は同一Gの全候補で共通になるため、将来CIMの種を選別する段階では候補解sも入力する必要がある。

## 1. 優先する先行研究

### 1.1 グラフ特徴量から探索法を選ぶ: MQLib

Iain Dunning, Swati Gupta, John Silberholz (2018), **What Works Best When? A Systematic Evaluation of Heuristics for Max-Cut and QUBO**, INFORMS Journal on Computing 30(3), 608–624.

- [著者の公式実装と書誌情報](https://github.com/MQLib/MQLib)
- [論文PDFの公開場所](https://github.com/MQLib/MQLib/blob/master/paper/SECM_final.pdf)
- [公開特徴量データ](https://raw.githubusercontent.com/MQLib/MQLib/master/data/metrics.csv)

Max-Cut/QUBOの問題特徴量から、適したヒューリスティックを機械学習で選ぶ。公開CSVには次数、クラスタリング係数、次数相関、近隣次数、core、重み、固有値関連などの特徴量が含まれる。今回確認した根拠は著者のリポジトリ説明と特徴量CSVであり、PDF本文はブラウザ取得に失敗した。

**今回との接点:** G22/G55/G70の構造の違いを定量化して、CIM、GA、SAの性能差と関連づける直接的な出発点。まず同じ系統の明示的特徴量を計算して比較する。

**区別:** アルゴリズム選択と個々のCIM初期解の将来価値予測は異なる。特徴量名に固有値があっても、正規化やどの行列の固有値かをコード確認せずに再現したとは扱わない。

### 1.2 分解できる構造を評価する

Daniel Rehfeldt, Thorsten Koch, Yuji Shinano (2023), **Faster exact solution of sparse MaxCut and QUBO problems**, Mathematical Programming Computation 15, 445–470.

[出版社の全文](https://link.springer.com/article/10.1007/s12532-023-00236-6)

Section 4.1は、連結成分だけでなく二重連結成分を独立に解けることと、小さな成分の列挙による処理を説明する。削減処理を組み込んだ厳密解法の研究。

**今回との接点:** 成分数、橋、関節点、最大二重連結ブロックの頂点数を測る根拠。元の頂点数より、分解・削減後に残る部分の大きさが有用な可能性がある。橋とは除去すると成分数が増える辺、関節点とは除去すると成分数が増える頂点を指す。

**区別:** これは厳密解法の構造利用であり、これらの特徴量だけでGA/SAの最終品質を予測できると実証した論文ではない。

### 1.3 スペクトルとMax-Cut

Luca Trevisan (STOC 2009; preprint 2008), **Max Cut and the Smallest Eigenvalue**.

[著者のプレプリント](https://arxiv.org/abs/0806.1978)

非負重みのMax-Cutに対し、最小固有値を用いるスペクトル的な近似法を与える。

**今回との接点:** 通常の連結性に加え「二部グラフにどれだけ近いか」を見る根拠。全辺が正のMax-Cutでは奇数長の閉路は全辺を同時にcutできず、この構造を考慮する必要がある。

**指標設計の提案:** 正規化ラプラシアンの第2固有値による連結性と、正規化隣接行列の下端固有値による二部性は別の特徴として扱う。G55/G70は非連結なのでグラフ全体の第2ラプラシアン固有値は0になり、これだけでは比較できない。最大連結成分や主要ブロック内でも計算する。小さな二部成分による最小固有値-1も、主要部の二部性を意味しない。

固有値やそのギャップからCIMの偏りを説明することは研究仮説であり、上記の近似理論がCIMの挙動を保証するわけではない。

### 1.4 平均次数以外の疎さと局所探索

Gregory Schwartzman (ESA 2024), **Local Max-Cut on Sparse Graphs**.

[論文と公開PDF](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ESA.2024.98)

Arboricityを用いて局所探索FLIPの平滑化計算量を解析する。グラフ全体の平均的な疎さに加え、部分グラフにも密な領域がないかを考える動機になる。

**今回との接点:** core numberの分布や最大値、密な部分グラフの構造を調べる理論的背景。

**区別:** Arboricityとcore numberは同一の指標ではない。また確率的な重み摂動の仮定を持つ計算量の結果であり、全重み+1のG-setやSA/GAの品質保証へそのまま適用しない。

## 2. Transformerの先行研究

### 2.1 グラフ構造を学習する: GraphGPS

Ladislav Rampášek et al. (NeurIPS 2022), **Recipe for a General, Powerful, Scalable Graph Transformer**.

[論文](https://arxiv.org/abs/2205.12454)

位置・構造符号化、局所message passing、global attentionを組み合わせる。グラフ構造をモデルに入力する方法を検討する基盤になる。効率的attentionを選ぶ構成でN+Eに線形の計算量を目指すもので、任意の設定が線形という意味ではない。

**今回への応用案:** core、ブロック情報、次数、スペクトル位置情報を構造符号化へ入れ、後段の性能を予測する。ただしこの論文自体はCIM候補の選別を検証していない。

### 2.2 Graph TransformerでMax-Cut探索: MARCO

Andoni I. Garmendia, Quentin Cappart, Josu Ceberio, Alexander Mendiburu (IJCAI 2024), **MARCO: A Memory-Augmented Reinforcement Framework for Combinatorial Optimization**, 6931–6939.

[本文PDF](https://www.ijcai.org/proceedings/2024/0766.pdf) / [公式実装](https://github.com/TheLeprechaun25/MARCO)

Graph Transformerを用い、辺の構造情報と現在の解・探索履歴を利用して探索方策を学習する。Max-Cutを扱うため、Transformerを今回の問題に適用する直接的な参考になる。

**区別:** GA/SAへ渡す種の価値を学習する論文ではなく、探索を行う方策の研究。G70の10,000頂点へそのまま拡大して安価に推論できるとは確認されていない。通常の全点attentionはN²の組を扱うため、効率的attention、疎なmessage passing、ブロック集約を比較する必要がある。

### 2.3 「この状態からの将来価値」を学習する: ECO-DQN

Thomas D. Barrett et al. (AAAI 2020), **Exploratory Combinatorial Optimization with Reinforcement Learning**.

[論文](https://ojs.aaai.org/index.php/AAAI/article/view/5723)

グラフと現在の状態をMPNNで処理し、頂点反転の将来報酬をQ値として学習する。Transformerではないが、「現在のcutだけでなく、ここから何が得られるか」を学習する設計上の参考。

そのQ値は学習した方策に対する値であり、既存GA/SAの到達品質ではない。今回の後段ソルバに対応する教師データが必要になる。

## 3. 手元の入力ファイルを実測した結果

入力はinput/G22.txt、G55.txt、G70.txt。全辺重みは+1。宣言された頂点をすべて含めて集計し、孤立点を省略していない。連結成分数には孤立点を含む。

|---|---:|---:|---:|
| 頂点数 | 2,000 | 5,000 | 10,000 |
| 辺数 | 19,990 | 12,498 | 9,999 |
| 平均次数 | 19.9900 | 4.9992 | 1.9998 |
| 連結成分数 | 1 | 32 | 1,598 |
| 孤立点 | 0 | 31 | 1,354 |
| 最大連結成分の頂点数 | 2,000 | 4,969 | 8,013 |
| 橋 | 0 | 180 | 3,605 |
| 関節点 | 0 | 179 | 2,770 |
| 最大二重連結ブロックの頂点数 | 2,000 | 4,789 | 4,798 |
| 2-coreの頂点数 | 2,000 | 4,789 | 4,798 |
| 2-coreの辺数 | 19,990 | 12,318 | 6,394 |
| 最大core number | 14 | 3 | 2 |
| 独立閉路数 m-n+c | 17,991 | 7,530 | 1,597 |
| 三角形数 | 1,395 | 23 | 0 |

2-coreとは、次数0・1の頂点を反復除去して残る誘導部分グラフ。一般に2-coreと最大二重連結ブロックは同じではないが、今回の3入力では頂点数が一致した。

G70では最大二重連結ブロックの大きさがG55とほぼ同じで、辺数やcore構造は異なる。元の頂点数だけではこの違いは見えない。G70には三角形がないが、別途NetworkXの二部性判定では非二部グラフだった。三角形やクラスタリング係数だけでは長い奇数閉路を捉えられない。

正重みの橋は、片側を丸ごと反転して他辺のcut状態を変えずにcut可能である。したがって橋・木状の部分と主要ブロックを分けた品質集計には意味がある。ただし木状の部分の配置も、元の頂点反転に基づくGA/SAの到達過程に影響し得る。構造分解で目的関数が簡単になることと、現行ヒューリスティックの挙動が不変になることは別。

**検証:** 独立なBFS集計とNetworkXの頂点数・辺数・成分数・孤立点数・最大成分サイズが全3入力で一致した。入力SHA256はJSONに保存。

- 拡張集計: `results/2026-09-21/graph_connectivity/v2_structure_G22_G55_G70/summary.json`

## 4. 研究へのつなぎ方（本調査からの提案）

### 第一段階: グラフ構造と性能差を結ぶ

まず、次数分布、成分・橋・ブロック、core分布、主要部のスペクトルを説明変数にする。目的変数は、同じ計算予算でのCIM/GA/SAの最終品質や目標到達率。MQLibの方針を基準に、明示的特徴量と回帰・ランキングモデルで予測可能性を調べる。

G22/G55/G70だけではグラフ単位のサンプル数は3であり、多数のCIM解を生成しても独立なグラフ例数は増えない。一般化を主張するには他のG-setや複数の生成グラフを加え、グラフ単位で訓練・評価を分割する。3グラフの説明的比較と未知グラフへの予測能力は分けて報告する。

### 第二段階: 構造を使ってCIMの種を評価する

グラフだけの特徴phi(G)を、候補sの配置と組み合わせる。

`V_SA(G,s;B) = E[予算B以内にSAが得る最良cut | 初期解s]`

温度・停止条件なども固定する。GAでは交叉相手や集団Pとの相性があるため、`V_GA(G,s,P;B)`として集団への追加・置換の効果を測る設計が必要。

候補ごとの入力には、ブロック別cut、core別cut、未cut辺の局所的な集まり、1頂点反転gainの分布などが考えられる。単なるcut値や平均次数を超える説明力があるかを比較する。孤立点や連結成分全体の反転ではcut辺配置が変わらないため、頂点ハミング距離と辺のcut状態の違いを区別する。ただしGAの実装がこの反転対称性に対して同じ軌跡を取るとは限らない。

### 第三段階: Transformerの追加価値を評価する

手設計特徴量＋小さなモデル、MPNN、Graph Transformerを順に比較する。グラフだけに依存する構造特徴は一度計算して再利用できる。解sも含む層の出力は候補ごとに再計算が必要であり、すべてをキャッシュできるわけではない。

教師値は現在のcutや短期改善量だけでなく、所定予算後の到達品質・目標到達率を用いる。初期cutを揃えた比較を含めると、「現在の値が高いから選ばれただけ」と区別しやすい。評価指標は予測誤差だけでなく、実際に選別後GA/SAの成績が上がるか。CIM生成、特徴計算、モデル推論、後段探索を合わせた時間を比較し、学習の準備コストも別記する。

2026-09-14のGA軌跡ではG70全CIM集団の多様性とgapが停滞していた。今回の橋・coreの違いは調査すべき仮説を与えるが、停滞の原因が橋や孤立点だと実証したわけではない。

今回確認した範囲では「グラフ構造に条件づけたTransformerでCIM解のGA/SA初期値としての将来価値を予測し、大量候補を選別する」構成そのものの実証は見つからなかった。類似要素は既存研究にあるため、未発見を新規性の証明とは扱わない。
