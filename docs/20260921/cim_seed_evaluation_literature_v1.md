# CIM解をGA・SAの有望な種として評価するための先行研究

調査日：2026-09-21。対象：G22・G55・G70のMax-Cut、CIMで生成した解の選別、グラフ構造と解構造、Graph Transformer。論文本文・著者公開版・出版社の概要を区別して確認した。網羅的な系統レビューではない。

## 研究目的の定式化

目的は、CIMで大量に生成した解を、**後段のGA・SAに与えたときの到達品質**で安価に順位付けすることである、と解釈する。

グラフそのものの次数、密度、連結成分数は問題間の違いを説明するが、同じグラフから生成した解には共通である。種の選別には、少なくとも「グラフG＋候補解s」を入力する必要がある。

- SA：`V_SA,B(G,s) = E[予算B内に到達する最良cut | 初期解s]`。温度スケジュールなどの設定も固定または入力する。
- GA：候補解単体の価値だけでなく、交叉相手t・集団Pとの相性を考える。`V_GA,B(G,s,t)`、または候補をPへ追加・置換したときの期待最良値の変化を予測する。
- 改善量だけを最大化すると、初期値が悪く改善余地の大きい解を選びやすい。最終到達cutや目標cut到達確率を主目的にし、改善量は補助ラベルにする。

これらは本調査からの設計提案であり、以下の各論文がそのまま実証した評価関数ではない。今回確認した範囲では、「CIM候補をGraph Transformerで評価し、その予測だけでGA/SA用の種を選別する」という構成そのものの実証は見つからなかった。未発見を新規性の証明とは扱わない。

## 先行研究：読む優先順位

### 1. Partition Crossover for Pseudo-Boolean Optimization

Renato Tinós, Darrell Whitley, Francisco Chicano, FOGA 2015, pp.137–149。
[出版社の概要・DOI](https://doi.org/10.1145/2725494.2725497)。確認範囲：出版社概要。

変数間の相互作用グラフを利用し、親同士で異なる変数を相互作用しないq個の集合に分割できれば、各集合の部分評価から2^q通りの組み合わせの最良を求める交叉。Max-Cutは辺ごとの2変数項からなるため、この考え方を適用できる。

**今回との接点**：親のハミング距離だけでなく、「異なる頂点がどんな連結部分に分かれるか」「どの部分でどちらの親が優れるか」を測れる。親2解の組み合わせやすさを評価する最優先の参照。

**限界**：保証はこの交叉の候補集合内の最良であり、大域最適性や後続GAの性能の保証ではない。現在のリポジトリはgrouping crossoverなので、PXによる評価と実際の交叉後の改善の対応を検証する必要がある。

### 2. A Memetic Approach for the Max-Cut Problem

Qinghua Wu, Jin-Kao Hao, PPSN 2012, pp.297–306。
[著者公開PDF](https://leria-info.univ-angers.fr/~jinkao.hao/papers/WuHaoPPSN2012.pdf)。確認範囲：本文。

G-setを用い、複数親に共通する頂点のグループを保存する交叉と、摂動付きTabu Searchを組み合わせる。1頂点反転の増分評価、品質と距離を用いた集団管理も扱う。

**今回との接点**：リポジトリのGAが参照する系統。親の共通部分を残す設計なので、親の配置の違いが良い子に変換されるかを調べる基準になる。

**限界**：CIM解の将来価値を学習する論文ではない。共通部分の保存、多様性の増大、将来の改善を同じものとして扱わない。

### 3. Exploratory Combinatorial Optimization with Reinforcement Learning（ECO-DQN）

Thomas D. Barrett, William R. Clements, Jakob N. Foerster, A. I. Lvovsky, AAAI 2020。
[論文ページ](https://ojs.aaai.org/index.php/AAAI/article/view/5723)、[本文PDF](https://ojs.aaai.org/index.php/AAAI/article/download/5723/5579)。確認範囲：本文。

Max-Cutの状態とグラフをMPNNへ入力し、各頂点反転の将来報酬をQ値として学習する。完成した任意の解から探索でき、2000頂点級のG-setも評価対象に含む。

**今回との接点**：「今のcut」から一歩進み、「この状態から探索すると何が得られるか」を学習する直接的な先行研究。

**限界**：Q値は学習した探索方策に対する値であり、そのまま既存SA/GAの到達品質を意味しない。候補選別へ転用するなら、使用する後段ソルバで教師ラベルを作る。

### 4. MARCO: A Memory-Augmented Reinforcement Framework for Combinatorial Optimization

Andoni I. Garmendia, Quentin Cappart, Josu Ceberio, Alexander Mendiburu, IJCAI 2024, pp.6931–6939。
[本文PDF](https://www.ijcai.org/proceedings/2024/0766.pdf)、[公式コード](https://github.com/TheLeprechaun25/MARCO)。確認範囲：本文と公式実装の説明。

Graph Transformerへグラフ・現在解・過去の類似解から取得した情報を入力し、探索行動を選ぶ。Max-Cutを含む実験で、履歴を用いた探索と解の重複回避を扱う。

**今回との接点**：Transformerで「結合構造＋解」を扱うという発想に非常に近い。現在の候補集合に対して重複する解を避ける設計にも参考になる。

**限界**：これは探索方策であり、CIM種の価値予測器ではない。報告の評価グラフは最大1200頂点級。G55/G70への速度・メモリ・精度は別途検証が必要。

### 5. Learning to Explore and Exploit with GNNs for Unsupervised Combinatorial Optimization（X2GNN）

Utku Umur Acikalin, Aaron Ferber, Carla P. Gomes, ICLR 2025。
[会議論文PDF](https://proceedings.iclr.cc/paper_files/paper/2025/file/e944bacecce6b06374ac39b260348db0-Paper-Conference.pdf)、[公式コード](https://github.com/utkuumur/X2GNN)。確認範囲：本文。

複数の解を結合したグラフ表現で同時に生成・改善する。Max-Cutでは、頂点の所属の違いだけでなく、cutされる辺に基づく多様性項を使う。

**今回との接点**：解集合の評価と、辺の状態を利用した多様性評価。孤立頂点の符号差を多様性として数えない表現の先行例として参考になる。

**限界**：下記の辺状態ハミング距離は本調査の候補指標であり、論文の学習損失そのものではない。X2GNNはCIM候補を選別するモデルでもない。

### 6. Recipe for a General, Powerful, Scalable Graph Transformer（GraphGPS）

Ladislav Rampášek et al., NeurIPS 2022。
[会議論文ページ](https://papers.nips.cc/paper_files/paper/2022/hash/5d4834a159f1547b267a05a4e2b7cf5e-Abstract-Conference.html)。確認範囲：会議掲載概要。

位置・構造の符号化、局所メッセージパッシング、大域attentionを組み合わせる設計。効率的なattentionを用いることで大規模グラフを扱う構成を示す。

**今回との接点**：G70の1万頂点に対する学習器の設計候補。通常の全頂点間attentionは1層・1headあたりN^2個の組を扱うため、軽量GNNや疎・線形attentionとの比較が必要。

**限界**：GraphGPSという名称だけで計算量が線形になるわけではなく、選ぶattention等に依存する。種の有望度予測への有効性はこの論文では実証されていない。

### 7. PageRank centrality for performance prediction: the impact of the local optima network model

Sebastian Herrmann, Gabriela Ochoa, Franz Rothlauf, Journal of Heuristics 24, 243–264, 2018（オンライン公開2017）。
[出版社ページ](https://link.springer.com/article/10.1007/s10732-017-9333-1)。確認範囲：出版社概要。

局所最適解を節、探索で移動する確率を辺とするLocal Optima Network（LON）を用い、探索性能とネットワーク指標の関係を調べる。SAと反復局所探索では、性能を説明するのに適した辺の定義が異なる。

**今回との接点**：解が「どの良い領域へ移れるか」を考える理論的な枠組み。G22自体のPageRankとは異なる、解空間上のネットワークである。

**限界**：G22/G55/G70のCIM候補を安価に選ぶことを実証した研究ではない。大規模問題の完全なLON構築は現実的でなく、短い探索から部分的に推定する必要がある。PageRankの高さだけで種の良さを断定できない。

### 8. Graph Representation Learning with Graph Transformers in Neural Combinatorial Optimization

Tianze Wang, Amir H. Payberah, Vladimir Vlassov, ICMLA 2023, pp.488–495。
[著者公開PDF](https://payberah.github.io/files/download/papers/cop_graph_transphormer.pdf)。確認範囲：本文冒頭・課題定義。

Graph TransformerでTSP/JSSPの問題インスタンスの最適コストを予測する研究。

**今回との接点**：グラフを入力してスカラー評価値を出す構成の参考。

**限界**：Max-Cutでも初期解の改善可能性予測でもなく、グラフ自体のコスト予測。今回に使うには解の状態と後段ソルバの条件を加える必要がある。

孤立頂点の符号はcutに影響しない。また、ある連結成分内の全スピンを一括反転しても、どの辺が切れるかは変わらない。これはMax-Cut目的関数から直接導ける。

したがって、これまでの「グラフ全体の反転だけを同一視するハミング距離」には、**目的関数上の違いがない符号差が含まれ得る**。G70で特に重要である。ただし、過去の多様性差やGA停滞がこれで説明できるかは、保存された実際の集団を再解析しないと分からない。

GAの交叉実装が成分ごとの反転に不変とは限らない。数学的に同じcut表現でもアルゴリズムの挙動は変わり得るため、正規化前後の性能を別に測る。

## 最初に比較したい評価指標（以下は提案）

### A. 解単体：局所的な動きやすさ

cutを `C(s) = (1/2) Σ_(i,j in E) w_ij(1-s_i s_j)`、スピンを±1とすると、頂点iを反転したときの増分は

`g_i(s) = Σ_j w_ij s_i s_j`。

その最大値、分位点、正・ゼロに近い頂点の割合、そうした頂点が作る部分グラフの成分構造を特徴にする。複数頂点Sをまとめて反転する増分は、境界辺について `Σ_(i in S,j outside S) w_ij s_i s_j`。

これは安価な手作り特徴だが、1-flip局所最適では全g_iが非正になるため、単独で将来の脱出可能性は決められない。短いSA/TSプローブ後の品質を比較対象に加える。

### B. 解の組：辺状態の違い

各辺について `z_ij(s) = (1-s_i s_j)/2` とし、2解の辺状態の平均不一致率を測る。

`d_E(s,t) = Σ_E |w_ij| |z_ij(s)-z_ij(t)| / Σ_E |w_ij|`。

孤立頂点と成分ごとの全反転の違いを数えず、目的関数に関わる配置差を測れる。距離の大きさが改善に有利かは別途学習・検証する。X2GNNの辺に基づく多様性という考え方が参考になる。

### C. GA向け：交換できる部分構造

候補sと参照親tが異なる頂点集合Dを作り、誘導部分グラフG[D]を調べる。各成分は、共通頂点を固定すれば他成分と独立に親を選べる。

特徴候補は、成分数・大きさの分布・最大成分比率・境界重み・部分評価差。成分ごとに優れた親を選んだPXの改善量も、直接計算できる比較指標となる。

ただし**成分数を増やすだけでは不十分**。孤立点や親の部分評価が同じ成分ではcut改善はなく、各成分で同じ親ばかり勝つ場合も良い親を超えない。役に立つのは「異なる親が相補的に良い部分を持つこと」。複数の参照親に対して評価し、集団としての相性を測る。

### D. 学習器：後段の到達品質を予測

入力は、重み付きグラフ、候補の辺状態、局所gain、必要ならCIM振幅や生成条件。GAでは親2解や現在の集団の情報も加える。グラフの次数・core・スペクトル・コミュニティ等は補助特徴として使い、グラフだけの情報に限定しない。

出力は指定予算後の期待最良cut、目標cut到達確率、または候補間の順位。まず手作り特徴＋単純な回帰器、次にMPNN、次に軽量Graph Transformerを同じデータで比較する。

教師ラベルは実際のSA/GAを複数乱数で走らせて作る。現在のcutを教師にするだけでは「将来よい種か」の予測にはならない。学習した探索方策のQ値を別ソルバの価値と取り違えない。

## 検証の組み方

1. **表現を整える**：孤立頂点、成分ごとの反転、辺状態を区別し、保存済み集団の多様性を再評価する。
2. **教師データ**：CIMの生成条件とseedを変えて候補を作り、固定のSA/GA設定・短中長の予算で到達品質を記録する。GAでは初期TSとその後の世代を区別する。
3. **比較対象**：ランダム選別、cut上位、cut＋ハミング距離、cut＋辺状態距離、短い探索プローブ、学習した順位付けを比較する。
4. **分割**：同じ軌跡や同じ解の対称変換を訓練・テストへ分散させない。同じG22の未見候補への予測と、未見グラフへの汎化は別実験にする。3つのグラフで多数の解があっても、多数の独立グラフがあることにはならない。
5. **評価**：候補順位の相関だけでなく、選別した上位k解から後段が実際に得た最良cutを評価する。初期cutを揃えた比較も行い、単なる現在品質の再現を避ける。
6. **時間**：CIM生成＋特徴計算＋推論＋後段探索の総時間を揃える。学習・教師作成コストは別に示し、何回利用すれば回収できるかを見る。

同じグラフなら構造の前処理や埋め込みの一部を再利用できる一方、解に依存する評価は候補ごとに必要である。全体の高速化は、評価器の推論が省略できた後段探索より安いときに成立する。

## この研究で狙える位置づけ

既存研究を踏まえた候補テーマは、**「グラフ構造と解の辺状態に基づく、CIM生成解の後段探索価値の予測と選別」**。

Transformerを使うこと自体よりも、実際のGA/SAに対する価値を教師にすること、Max-Cutの対称性を考慮すること、個体と親・集団の相性を区別すること、選別コストを含む時間で有効性を示すことが研究上の焦点になる。

最初に読む3本は、**Partition Crossover、ECO-DQN、MARCO**。現在のGAとの接続にはMACUT、辺状態の多様性にはX2GNN、大規模化にはGraphGPSを併読する。
