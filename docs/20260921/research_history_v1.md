# これまでの研究の流れ

整理日：2026-09-21。対象：このリポジトリで確認できた2026-04-23〜2026-08-18の実験記録。以下の流れは、記録をもとに研究の問いの変化を整理したもの。新たな実験や外部論文の再検証は行っていない。

研究の中心は、**CIM（コヒーレントイジングマシン）の数値モデルを使ったMAX-CUT探索を改善し、他手法と組み合わせたときの役割を明らかにすること**と整理できる。

問いは「CIM自体の性能を上げられるか」から、「CIMの解を後段の探索に渡すと役立つか」、さらに「その効果を解の品質・多様性・問題構造から説明できるか」へ進んでいる。

## 1. CIM自体を改善する段階

最初に、ファイバーループ型CIMのモデルを実装し、既存手法と比較できる基盤を整えた。続いて、ファイバー長、飽和係数、損失、ポンプ増加量、結合強度を調整した。

5月のスイープでは、ラウンド数を1500から10000へ増やして個別に調整しても、平均値の改善は約6.6にとどまった。この観測から、計算量だけでなく、増幅・探索・凍結の進み方を変える方向へ研究が進んだ、と整理できる。

6月にはポンプ制御とPTを調べた。重要なのは、最初の改善の説明を対照実験で修正した点である。

- **CIM内部のPT**：3本のランプを使う構成で交換の有無を比較すると、平均は交換なし13291.9、交換あり13294.3、最良はいずれも13337。1本から3本に増やした寄与の方が大きく、改善を交換そのものの効果とは説明できなかった。
- **ポンプ制御**：6/8の記録では、探索を長く保ち、後半で穏やかに発振させる設定で平均約+7の改善。ただしG22での結果で、他問題への汎化は未確認。
- **モデルの再確認**：簡略モデルによるPumpBench実験を、リポジトリのCIM/CAC実装で再検証。シグモイドと線形の順位が逆転し、モデルを変えると結論も変わることを確認した。

ここでの「CIM内部にレプリカ交換を入れる実験」と、後の「CIMの解を別のPT-ICMソルバに渡す実験」は、仕組みも検証対象も異なる。

## 2. CIMの解を他の手法に渡す段階

6/19の比較では、CIM単独よりも、その解をTabu Searchなどで改善する方が良い結果を得た。例えば記録上、K2000ではBKSとの差がCIM単独794からCIM→TSで120へ縮小した。一方、同じ比較のGAは差33であり、ハイブリッドが最良の単独手法を超える結果ではなかった。

このため、問いを「CIMが一番強いか」から、**「CIMを前段に置くことで、後段の探索がどれだけ早く良い解に到達するか」**へ絞り込める。

7/24にはCIM→SA・GA・PT-ICMを比較し、7/26には初期化以外の条件を揃える追試や長時間の評価へ進んだ。後の記録を優先して整理すると、次のようになる。

| 後段手法 | 現在の記録から言えること |
|---|---|
| SA | 温度・反復数・シード・初期化後の乱数位置を揃えると、G22/G55では10万・30万反復でCIM初期化が有利。100万〜3億反復の測定点では有意差を確認できなかった |
| GA：1個体をCIM解に置換 | G22では0〜3世代の初期改善を確認。G55では50世代まで有利で、効果の持続時間は問題によって違う |
| GA：全個体を異なるCIM解で初期化 | G22では50世代、G55では120世代で差が不明確になった。G70では800世代でも有利。K2000では測定した0〜800世代で有意差を確認できなかった |
| PT-ICM：温度ラダーへCIM解を配置 | G22/G55/G70では600 sweepsまで有利、1800 sweepsでは有意差を確認できなかった。K2000では記録の最終点1800 sweepsでも有利だった |

いずれも各問題16試行の記録に基づく。「有意差を確認できない」は同等性の証明ではなく、記録の停止点も厳密な効果消失時刻ではない。

また、同じ反復数・世代数での改善と、CIM生成時間まで含めた同じ総時間での優位は別の評価である。初期化による品質改善だけで費用対効果を断定しない。

**更新すべき古い結論**：7/24のSAには初期化と温度設定の違いが混在していた。7/26の条件を揃えた追試からは、「CIM初期化は長時間で必ず悪化する」ではなく、「初期の優位は長時間では確認できなくなる」とまとめるのが適切。

## 3. 解の品質と多様性を調べる段階

8/18には、初期解としての効果を理解するため、解の値だけでなく、解同士がどの程度違うかを比較した。全体反転した分割を同一視したハミング距離を使い、共通のTabu Searchをかけた後にも距離が残るかを調べた。

- CIMの多様性順位は、G22で2位、K2000で4位、G55で5位、G70で6位（6手法中、多様な方から数える）。**「CIMは常に他手法より多様」という仮説は、この比較では支持されない。**
- 全手法の生の出力を集めた上位25%に、CIMの解はどの問題でも入らなかった。離れた解を出すことと、高品質な候補を供給することを分ける必要がある。
- 共通TSの後も、CIMの解間距離はK2000で0.446→0.444とほぼ残った。単に未収束な揺らぎだけでは説明できない構造差を示唆する。ただし、後処理後も手法間の品質が完全に揃ったわけではない。
- 収集した上位解の平均距離はG22で0.070、K2000で0.353。良い解が近くに集まる場合と、離れた良い解が複数存在する場合があり、多様性の意味は問題によって異なる。

これは「多様性が初期化効果の原因」と証明した結果ではない。時間予算にはずれがあり、G55/G70のCIM設定はG22からの流用を含む。共通TSも大規模問題ではほとんど改善していないため、観測された範囲に限定して解釈する。

## 現在の到達点と次の問い

現在の研究は、**CIMを初期解生成器として使う効果と限界を、後段手法・計算予算・問題構造によって整理する段階**にある。

支持されているのは、特定の問題・予算ではCIM初期化が探索の立ち上がりを改善すること。その効果は一律ではなく、長時間で薄れる場合も、測定範囲内で残る場合もある。最良の単独手法を常に上回ることや、多様性だけで改善が決まることは示されていない。

次に問うなら、**「同じ品質の初期解でも多様性を変えると改善するのか」「同じ総時間でCIM生成に時間を使う価値があるのか」**が、これまでの流れにつながる。この2点は今後の提案であり、完了済みの結果ではない。
