# 事前登録：CIM の線形段が谷を選び、非線形段が谷の奥へ運ぶか（実験 D、G22）

登録日：2026-11-14（実験を回す前に書いた。結果を見て書き換えない）

## 背景

- 検証1（実験 B、`results/2026-11-12/start_distance_causal/v1_…`）：SA（T₀ = 2.0）で仕上げた後の質は、開始解が最良解の谷（最も近い BKS 解までの距離 d < 0.3）にいるかで決まる。CIM の解は 99.7% が谷の中にいる。
- 検証2（実験 C、`results/2026-11-13/eigvec_valley/v1_…`）：谷は J の最大固有ベクトル u₁ の側にある。CIM を使わず sign(u₁) から SA を回すと 0.151%（d = 0.303、谷の縁）。CIM の解からだと 0.097%（d の中央値 0.166、谷の奥）。
- 考え（11/14 の動画・進捗報告）：CIM の**線形段**（振幅が小さく、行列をかけるだけの間）が u₁ 側の谷を選び、**非線形段**（利得が飽和してから）が解を谷の奥へ運ぶ。

## 見る前にしたこと（正直に書く）

- CIM 1 本（seed 1000）の振幅と飽和度だけを見た（距離・重なりは見ていない）。振幅はラウンド 120〜360 で急に育ち、飽和度 γ⟨I_in⟩ は 240 で 0.03、360 で 0.22。これで線形段の終わりの定義を決めた。

## 定義

- 飽和度 s(k) = γ · mean_i (√η c_i + (Jc)_i)²。利得の指数が γI_in の割合だけ下がる量。
- **線形段の終わり k_lin**：試行ごとに、s(k) が初めて 0.01 以上になったラウンド（ラウンド 0〜600 は 2 ラウンドおきに記録）。
- 距離 d：sign(c) と最も近い BKS 解（89 個）との正規化ハミング距離（全反転は同じ）。谷の中 = d < 0.3。
- 重なり ov_k = |⟨sign(c), sign(u_k)⟩| / n、E = ov₁ − ov₂（実験 C と同じ）。

## 実験

- **D1（観察）**：CIM の seed プール 0〜3（seed 1000〜2023、1024 本、2400 ラウンド、sa_trajectory v3 と同じ）の途中の振幅を記録する。最良カット値が run_cim と一致することを確かめる。
- **D2（介入：非線形段を止める）**：sa_trajectory v3 の CIM 開始解と同じ 960 本（プール 0〜59 の上位 16 個）について、同じ seed の CIM を k_lin で止め、そのときの sign(c) から SA（T₀ = 2.0、5000 スイープ、seed 150,000,000 台）を回す。比べる相手は、同じ 960 本の CIM の解（最後まで回したもの）からの SA（sa_trajectory v3 の cim_T2）。

## 予測（主張の合否はこれで決める）

- **P1（線形段が u₁ 側を選ぶ）**：k_lin での E の中央値 > 0。かつ、k_lin での d の中央値は 0.25〜0.40（谷の縁。sign(u₁) の 0.303 に近い）。
- **P2（非線形段が奥へ運ぶ）**：d の中央値が k_lin から最終ラウンドまでに 0.05 以上小さくなる。その間 E の中央値は > 0 のまま。
- **P3（介入）**：k_lin で止めた解からの SA 後の BKS との差の平均は、最後まで回した CIM の解からより大きい（対応のある Wilcoxon 検定、p < 0.01）。大きさは 0.12〜0.20%（sign(u₁) の 0.151% に近い）。

## 外れたときの読み方

- P3 で差が 0.01% 未満なら、「非線形段が奥へ運ぶ」は G22 では支持されない（谷の奥へは線形段の時点で着いている、または SA が差を消す）。
- P1 で E ≤ 0 なら、線形段は u₁ 側を選んでいない（実験 C の解釈を見直す）。
- 合否にかかわらず全部報告する。G22 の 1 問題だけで、他の問題への一般化はしない。
