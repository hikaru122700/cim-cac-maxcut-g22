# ポンプ関数最適化 実験計画(2026-06-08)

戦略文書 [`0019_CIM_next_strategies.md`](0019_CIM_next_strategies.md) の **戦略A(時間発展=ランプ
スケジュールの改良)** を本丸として、CIM のポンプ関数(時間軌跡)の形状を最適化する。背景は
[`1156_CIM_PT_why_failed.md`](1156_CIM_PT_why_failed.md) と
[`1156_CIM_pump_fixed_and_linear_vs_sqrt.md`](1156_CIM_pump_fixed_and_linear_vs_sqrt.md)。

## 出発点(確定知見)
- CIM は時間発展(ランプ=焼きなまし)が本質。固定ポンプは負け、ランプが効く。
- 固定構成の PT スワップはほぼ無効。利得の主因は multi-start。
- → **「ランプ形状そのもの」を最適化する**のが最短の本丸。

## 確定した設計判断
1. **最適化対象は P 軸と g0 軸の両方を別軸として比較**する。
   ポンプは 2 層: 電力 $P(k)$ と利得項 $g_0(k)=2\kappa L\sqrt{P}$。分岐は $g_0=g_{0,\rm th}=\ln(1/\eta)$。
   同じ正規化形状 $s(\tau),\ \tau=(k{+}1)/K$ を「$P/P_{\rm th}$ に適用」と「$g_0/g_{0,\rm th}$ に適用」の
   2 通りで作り、どちらの空間で形状最適化すべきかをデータで判定する。
2. **手設計スイープ(Phase 1)と Optuna(Phase 2)の両方**を行う。手設計で効く族を見極め、
   Optuna でその族のパラメータを詰める。
3. **単一レプリカでポンプ形状の純粋効果を評価**する。multi-start(B)・ノイズスケジュール(D-3)
   との合成は後段。swap-ablation の教訓どおり、交絡なく純粋寄与を測る。

## 基準値(G22, K=1500, dP=0.05mW)
- $P_{\rm th}=37.96$mW, $g_{0,\rm th}=2.533$。
- 線形ベースライン終端: $P/P_{\rm th}=1.976$ ⇔ $g_0/g_{0,\rm th}=\sqrt{1.976}=1.406$。始端 $\approx0$。
- 線形電力ランプは round 760 で $P_{\rm th}$ を一定速度で素通り。

## ポンプ関数の族(設計空間)
正規化形状 $s(\tau)\in[0,1]$ を以下から取り、P 軸 / g0 軸で端点を揃えて適用:
- **linear** $s=\tau$(P 軸 linear = 現行ベースライン)
- **power** $s=\tau^{p}$($p{<}1$ 早上げ / $p{>}1$ 遅上げ)
- **sigmoid** 遅-速-遅(分岐近傍で加速)
- **critical-slowdown(区分線形)** しきい近傍 $u\in[0.9,1.1]$ に滞在(A-2 を直接エンコード)
- **two-phase** explore(しきい下で保持)→ freeze
共通ノブ: 始端・終端($u_{\max}$ 等)、形状パラメータ。$K$ は等計算量のため固定。

## 評価プロトコル(必須)
1. ベースライン = 単独線形ランプ CIM、**等計算量**($K$×trial 固定)。
2. 各形状を**同一 seed**で線形と対照し、mean / best / std / 既知ベスト比を報告。
3. 改善が std を超えるか明示。最終形状は**チューニングと別の held-out seed**＋**複数グラフ**で汎化確認。

## Phase 1 知見(2026-06-08, G22, 端点一致)
**重要(手法)**: 全形状は同一 seed なので **per-seed のペア差 Δ で評価**すべき。32 seed の非ペア比較では
「誤差」に見えたが、**200 seed＋ペア比較**にすると seed 起因のばらつきが相殺され有意差が出た(z 最大±18)。

- **有意に改善する形状(z≥2)**: ペアΔmean
  - **g0軸 linear** +5.35 ±3.63 (z=+2.95), best=13337
  - **P軸 power p=2.0(遅上げ)** +5.18 ±3.78 (z=+2.74)
  - この2つは**物理的に同一軌跡**: P∝τ² ⟺ g0=2κL√P∝τ。すなわち**「利得 g0 を線形に上げる」ランプ**で、
    別パラメータ化が一致(強い整合性チェック)。
- **有意に悪化**: P軸 power p=0.5(早上げ, −30), g0軸 sigmoid(−37), P軸 sigmoid(−22), 臨界減速(両軸 −12/−21),
  g0軸 power p=2.0(−7)。**臨界減速(H1)・シグモイドはこの端点では明確に悪い**。
- **結論**: 現行の線形電力ランプ(→ g0∝√k, 利得が早く立ち上がる)は**有意に最適でない**。
  **利得 g0 を線形に上げる**(g0∝k; しきい超えが round760→1055 と遅く、低利得探索を長く取る)方が +5.3 良い。
  ただし効果は小さく**形状は2次効果**。**未検証の主レバーは端点/しきい超えタイミング(H2)**。
- → Phase 2: ペア200 seed 手法(±5 を検出可能)で、linear-gain を基準形状に **端点 u_max/u_0・しきい超え
  タイミング(two-phase の explore 割合)** を掃引。勝者は held-out seed＋複数グラフで汎化確認。

## Phase 2 知見(2026-06-08, G22, ペア200 seed)
基準形状 = linear-gain。2つの 1-D 掃引で「終端準位」と「しきい超えタイミング」を交絡分離。
- **2A 終端利得 $u_{\max}$**: $u_{\max}\approx1.2$–$1.3$ で頂点 **Δmean +7.0(z≈3.5)**。$u_{\max}\ge1.8$ は
  **有意に悪化**(−6〜−10)。現行ベースラインは $u_{\max}=1.406$ まで上げており**やや過剰ポンプ**。
- **2B explore割合 $f$**(終端 $u_{\max}=1.4$ 固定): **遅くしきいを超えるほど単調改善**。f=0.3(round450)で
  −28、f=0.9(round1350)で **+7.2(z≈3.8)**。0 交差は f≈0.6(round≈900)。
- **統一した結論(レバー)**: **「しきい超えを遅らせ、過剰に上げない」**。すなわち低利得での探索を長く取り
  (しきい超え round 760→1100〜1350)、終端利得は控えめ($u_{\max}\approx1.3$)に。物理的に explore→gentle freeze。
- **効果は ~+7 mean(z≈3.5)と有意だが小さい**(13275.7→13282.9, +0.05%; best はほぼ不変)。**ポンプ関数は
  実在するが2次のレバー**。doc の「大レバーは multi-start」と整合。
- 残課題: 2B は f=0.9 まで単調 → さらに遅い超え(f≈0.95)の確認、$u_{\max}\times f$ の2D最適化(Phase 3.5)。
