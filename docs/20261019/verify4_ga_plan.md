# 検証 4：GA の初期集団を CIM で作る利点を、CIM の生成時間込みで比べる（実行前に固定）

作成日：2026-10-19。本実験（`ga_equal_time.py`）の結果を見る前にコミットする。時間の測定（`ga_cim_timing.py`）だけは先に行った。

## 位置づけ

論文の検証は 1〜3（種の価値の差・その予測・SA での選別）まで終わった。残る問いは 2 つある。

- 論文 §GA では，CIM の初期集団が G55・G70 でランダムな初期集団より良かった。ただし同じ世代数での比較で，CIM の生成時間を含めていない。SA では時間を揃えると，長い予算でランダム初期化が勝った。
- SA での選別では，ハミング距離で多様な候補を選ぶと悪化した。SA は候補ごとに独立に走るので，多様性は理論上得にならない。GA は交叉で解を組み合わせるので，多様な初期集団が効く可能性がある。

## 設定

- 問題：G22・G55・G70。GA のパラメータ（`PARAMS[ds]["GA"]`），CIM のパラメータとラウンド数（G22・G70 は 4800，G55 は 9600）は §GA の実験（`ga_diversity_trajectory.py`）と同じ。
- 16 trial。GA の seed は 20000〜20015（新しい seed，4 条件で共通）。CIM の seed は 3,020,000 から（新しい seed）。
- 各 trial で CIM 解を K = 4 × 集団サイズ 個作る（G22：60，G55：24，G70：32）。
- 初期集団は 4 通り。
  - **ランダム**：GA 既定のランダムな初期集団。
  - **CIM（選別なし）**：K 個のうち先頭の集団サイズ個（seed 順）。CIM は集団サイズ本だけ課す。
  - **CIM＋カット値**：K 個からカット値の上位を集団サイズ個。CIM は K 本を課す。
  - **CIM＋カット値＋ハミング距離**：カット値の上位 2 × 集団サイズ個から，最良を起点に「既に選んだものとの一致度の最大」が最小の候補を順に足す（全反転を同一視）。CIM は K 本を課す。
- どの条件も，GA は初期集団に TS をかけてから世代を進める（GA の実装どおり）。

## 時間の数え方

- ほかの計算と重なっても比が崩れにくいよう，1 スレッドの CPU 時間で数える（`ga_cim_timing.py`：CIM 1 本，初期集団の TS，GA 1 世代を交互に 3 回測り最小値）。
- CIM 条件の時刻：c × (CIM の本数) × t_cim + t_init + g × t_gen。ランダム：t_init + g × t_gen（初期集団の TS と世代の時間は条件ごとに測った値）。
- 選別の計算（K 個の並べ替えと距離）は CIM 1 本より十分小さいので数えない。
- **評価時刻 T_eval** = K × t_cim + t_init + 300 × t_gen（CIM＋カット値が CIM の時間を 1 倍払って 300 世代進む時刻）。各 trial のその時刻までの最良値を，BKS との差（%）にする。GA の開始前の時刻では，CIM 条件の最良値はそれまでに作った CIM 解のカット値の最大とする。
- 全条件を，T_eval に全条件・全倍率が届く世代数（5% の余裕）まで回す（下の「実行開始後に変えた点」）。
- CIM の時間の倍率 c は 1（主条件），0.1，0 の 3 通り。0.1 と 0 は，物理的な CIM で生成が速い場合の想定。

## 判定（主条件：c = 1，T_eval，有意水準 0.05）

- **V4a**：CIM（選別なし）がランダムより良い。問題ごとに片側 Mann–Whitney U 検定（16 対 16），3 問題で Holm の補正。
- **V4b**：CIM＋カット値＋ハミング距離が CIM＋カット値より良い。同じ CIM 候補・同じ GA seed で対応があるので，問題ごとに片側 Wilcoxon 符号順位検定，3 問題で Holm の補正。

## 副次（記述のみ，判定はしない）

- c = 0.1・0 での V4a・V4b と同じ比較，CIM＋カット値とランダム，CIM＋カット値と CIM（選別なし）。
- 時間と最良値の曲線。
- 初期集団の平均カット値と平均ペア距離（ハミング距離での選別が実際に距離を広げたか）。

## 予想（実行前）

- 時間の測定（`results/2026-10-19/ga_cim_timing/v1_G22_G55_G70_rep3`）：CIM 1 本は GA の 1 世代の 32 倍（G22），124 倍（G55），147 倍（G70）。T_eval は 40 秒（G22），44 秒（G55），54 秒（G70）で，ランダムはそれぞれ約 2200・3100・4200 世代進む。
- V4a は c = 1 では成り立たない。CIM（選別なし）でも CIM の時間がランダムの数百〜千世代分に当たるため。c = 0 では成り立つ。
- V4b はどちらもありうる。

## 実行開始後，結果を見る前に変えた点

- 当初は全条件を「ランダムが T_eval に届く世代数」まで回すとしていた。コードレビューで，CIM の時間の倍率 c = 0.1・0 では CIM 条件のほうが多くの世代を要し（G70 は 1 世代がランダムより 16% 短い），G70 で足りないことが分かった。最初の実行を G22 の CIM 生成の直後（GA の結果が出る前）に止めて出力を消し，世代数を全条件・全倍率の最大（G22：2365，G55：3433，G70：5247）に直して実行し直した。判定と評価時刻は変えていない。
- 解析は `eval_gens` を実行時の設定から読むように直した（小さい設定の動作確認で 300 を固定していたのが分かったため。本実行の値は 300 で同じ）。
