# 論文化計画（路線B）：CIM解の「後段での価値」を安価に見分ける

作成日：2026-10-16。確認したHEAD：`70d6e25`（2026-10-16、9/14の未追跡分をコミットした時点）。新たな実験は行っていない計画書。

## 論文の主張（目標）

> 同じカット値のCIM解でも、後段のSA/GAで到達できる品質は解の配置によって異なる。この差は安価な指標で予測でき、それで種を選別すると、CIM生成を含む同じ総時間で到達品質が上がる。

貢献を3段に分け、各段が単独でも成果になるようにする。

| 貢献 | 内容 | 現状 |
|---|---|---|
| C1 現象 | 同じcutのCIM解で後段の価値がばらつくことを、G-setで示す | 16スピンの1問題のみ（9/28） |
| C2 説明 | 安価な指標がcut以上の説明力を持つ | 経路長（全列挙、大規模では使えない）のみ |
| C3 実用 | 選別により同じ総時間で品質が上がる | 未着手 |

**主な後段はSA（とTS）にする。** 候補1個の価値をラベルとして定義しやすいため。GAは候補単体でなく集団との相性で価値が決まるので、拡張扱いとする（Phase 4）。

## Phase 0：実現できるかの判定と基盤確認（1〜2週）

### 0-1. G-setで「同じcutでのばらつき」があるかのパイロット【go/no-go】

路線Bの前提がG-setでも成り立つかを最初に確かめる。成り立たなければ計画を変える。

- G22・G55・G70で、独立seedのCIM候補を各256個生成する。
- 各候補にSA（予算B固定）を16回かけ、平均最良cutと目標到達率をラベルにする。
- 判定：cutで層別したときの層内のラベル分散が、ラベルの反復誤差（SA乱数による分散）より十分大きいか。
- 大規模問題ではcutの値が細かく分かれるので、「同じcut」はcutの区間か、cutで回帰した残差で扱う。
- 予算Bは短・中・長の3段階を試す。長いとどの候補も同じ品質に収束し、差が消えることがある。

### 0-2. GA実装の確認

GAは主軸ではないが、論文で使う限り「バグでは？」に答えられる必要がある。

- Wu & Hao (2012) に近い設定で、G-setの報告値（またはBKS到達率）を再現できるかを確認する。
- G70全CIM初期化での300世代の停滞を、交叉直後・子へのTS後・集団への採否に分けて記録して説明する。
- 9/28の「交叉+TS ≤ TSのみ」の結果が、G-set規模でも同じかを確認する。

## Phase 1：小規模で現象と指標を固める（2〜3週）

9/28の結果を「1問題・1つの見栄えの良い例」から一般化する。

- **問題集合：** 16〜24頂点のフラストレートした問題を約30個（対角辺の配置を変えた格子、ランダム3正則グラフなど）。2^24程度までは全列挙で最適値と経路長を計算できる。
- **開発用と検証用に分ける：** 問題を開発用と検証用に分け、指標と閾値は開発用だけで決める。
- **ラベル：** 候補ごとにSAを256回かけ、最適到達率を求める。
- **指標の候補：**

| 種類 | 指標 | 大規模での計算量 |
|---|---|---|
| 正解（参照用） | 非悪化経路長、最小障壁 | 全列挙が必要 |
| 安価 | 1-flip利得の分布、利得0の頂点数とそのまとまり、不満足辺の連結成分 | O(辺数) |
| 安価 | CIM最終ラウンドの振幅の小さい頂点の数・位置 | CIM実行時に無料 |
| 試し打ち | 短いSA/TSを数回かけた結果 | 小〜中 |

- **評価：** cut層内での順位相関（Kendall τ）と、問題を変量効果とした回帰で、cut以上の説明力（ΔR²）を測る。
- **成果：** 安価な指標が正解指標（経路長）とどれだけ一致するか、ラベルをどれだけ予測するか。

## Phase 2：G-setで検証する（3〜4週）

- **問題：** `input/` にある10問題（G1, G14, G15, G22, G23, G32, G39, G55, G70, G77）。ランダム・トーラス・平面型の各タイプを含む。必要なら G43, G48 などを追加する。
- **候補：** 各問題で512〜1024個の独立CIM run。同じrunの途中状態や全反転は独立サンプルに数えない。
- **ラベル：** Phase 0で決めた予算BのSAを16〜32回。反復数は0-1で測ったラベルの分散から決める。
- **データの分割：** 問題ごとに分ける（未見の問題でも予測できるか）。同じCIM runは同じ側に入れる。
- **主な結果：** 指標のcut以上の説明力、層内AUC、問題タイプ別の違い。グラフ構造の分析（9/21–22）と結びつけ、どのタイプで効くかを議論する。

**計算コスト：** 例えば10問題×1024候補×32回 ≈ 33万回のSA実行。Phase 0で1回あたりの時間を測ってから規模を確定する。

## Phase 3：選別の実用評価（約3週）

パイプライン：`CIMでK候補生成 → 指標計算 → 上位m個を選別 → SA/TS`

| 比較する選別法 | 位置づけ |
|---|---|
| ランダムに選ぶ | 最低限のベースライン |
| cut上位を選ぶ | 自然なベースライン |
| cut+従来の距離（多様性） | これまでの研究の延長 |
| cut+提案指標 | 提案手法 |
| 全候補に短いSAをかけて良いものを続ける（successive halving） | **最も強いベースライン**。指標はこれに勝つ（または計算コストで勝る）必要がある |
| CIMを使わずランダム初期化+同じSA | CIMを使う意味の確認 |

- **時間を揃えた比較：** CIM生成、指標計算、選別、後段探索をすべて含めて揃える。目標到達確率と時間の曲線（TTT/TTS）で示す。
- **統計：** 問題ごとのブートストラップ信頼区間。問題をまたぐ比較はWilcoxon検定、多重比較はHolm補正。
- **外部の参照：** MQLibの上位手法（BLSなど）の報告値と並べ、全体の位置を示す（勝つ必要はない）。

## Phase 4：仕組みと拡張（約2週、論文の後半または今後の課題）

- **CIM生成条件：** ノイズ、ポンプの立ち上げ、停止時刻を変えると、有望な種の出現率が変わるか。8/23の多様性の結果と、8/24の後半の改善がない時間帯（早期打ち切り）に結びつける。
- **GA：** 基準集団の1個体を候補で置き換えたときの最終品質の差。不一致部分の連結構造（Partition Crossoverの考え方）が効くか。
- **学習モデル：** 手作りの指標で足りない場合だけGNNやTransformerを検討する。

## リスクと代替案

| リスク | 代替案 |
|---|---|
| G-setではcutだけでほぼ説明できる | 小規模で効く条件・効かない条件の分析として論文にする。予算Bが短い領域に絞る |
| 短いSAの試し打ちに指標が勝てない | 指標を、試し打ちの前に候補を絞る安価な一次選別として位置づける |
| ラベルのノイズが大きい | 反復回数を増やす。目標到達率より分散の小さい平均最良cutを主ラベルにする |
| GAの不具合が見つかる | 修正し、過去のGA結果は再実行するか引用しない |
